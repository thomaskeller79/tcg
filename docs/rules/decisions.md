### D23 — Instant-speed marker (`^`) for activated abilities: default sorcery-speed
Generalizes D5's card-level instant/sorcery-speed split down to the **ability** level, and removes the need for a Champion-specific "can abilities be reactive?" special case (supersedes the former Open question 3 in `design-champions.md`). **Default: sorcery-speed** — any AP-costed ability (creature, Champion, or Companion alike) is playable only during its controller's own Action phase, and only while the stack (the Aether's pending region, D16) is empty — not as a response. **`^` marks an ability instant-speed:** usable in any priority window (D5), on either player's turn, same as a card-level instant. **Composes freely with the existing AP-cost flavors** — `^2*AP`, `^3!AP`, `^1AP` are all valid: `^` governs *when*, `!`/`*` govern *how the AP is consumed*, independent axes. **No new resource:** an instant-speed ability still spends the actor's own AP from its normal (refills-on-your-turn-only) budget, so acting reactively means that AP had to be held in reserve since the actor's own last turn — reactive plays cost you offense earlier, which is presumably the intended tension, not a gap (flag for playtest). → `design-economy.md`, `design-champions.md`.

### D22 — Companion: a new card type between Creature and Champion; second network root
**New card type**, deckbuilding-gated to specific Champion(s). Makes the game's channeling hierarchy explicit: **Creature** spends mana but can't draw it; **Companion** draws mana (bonds terrain) but can't share it — it keeps a **private mana pool**, spendable only on its own printed abilities; **Champion** draws *and* shares (D8/D9 unchanged). Shape: Creature's three numbers (Attack/Life/AP, D10) **plus** a private mana pool **plus** an AP-costed **Bond** ability (`x*AP`, same cost flavor as the Champion's `2*AP` Bond, D9 — priced more restrictively against the Companion's smaller AP total, so bonding crowds out most of its turn). Cast like a Creature (D20: drawn, paid in mana, summoned onto a bonded terrain). **Extends D8 rather than replacing it:** a Companion in play is a **second network root**, bonding terrain reachable from itself via already-bonded terrain, same reachability/pause mechanics as the Champion's root. **Ownership follows the bonder** — whichever root (Champion or a specific Companion) performs a bond determines which pool that terrain feeds (shared vs. that Companion's private pool); **a Companion's death un-bonds its own terrain outright** (reverts to unbonded, re-bondable later by any surviving root — same "undo, don't pause" vocabulary as un-summon, D16), since a Companion's bond is only as permanent as the Companion itself, unlike the Champion's (D8). Mana never crosses the shared/private boundary in either direction — this also governs **terrain control**: a terrain is controlled by whichever root bonded it (or by no one, if unbonded), and any of that terrain's own printed activated abilities can only be funded from the pool that node feeds (shared for Champion-bonded, that Companion's private pool for Companion-bonded). See `design-resources-terrain.md`. Move/Attack are also **network-dependent costs**, mirroring the Champion's realm-constraint shape (D9): cheaper once the Companion's own connection collapses, pricier while it stays connected. **Invariant preserved:** still exactly two resources, mana + AP (design-economy.md) — a Companion adds a second *pool instance* of mana, not a third resource. **Open:** deck/board count limits, whether Companions gate faction identity, meta-progression shape (parked to the meta-layer, post-M4); also surfaced a pre-existing table/prose contradiction in D9's Champion Move-cost description that needs a fix. → `design-companions.md`.

### D21 — Turn structure: Beginning / Action / End; per-action response windows
**Beginning of turn:** mana/AP **refresh** (covers creatures and the Champion alike, D9) — **simultaneously, no state checks**; then the active player puts their beginning-of-turn triggers into the Aether, then the opponent theirs (**APNAP** order → opponent's resolve first, LIFO). **No priority in this phase to start** (simple); active-player *choices* (upkeep costs) still work — only *opponent-reactive* upkeep needs a window, added later as a **data change** (phases are data, D3). *(Card draw is no longer an automatic Beginning-phase step — as of the D9 revision it's the Champion's `5*AP: Draw` action, taken in the Action phase.)* **Action phase:** active player plays spells, spends AP to move/attack/draw/bond/activate, in any order, until they choose to finish; **after every active-player action — including a move and including a deliberate pass — the inactive player gets a response window** (refines D5: windows now open per-action, not only on stack/Combat events; enables movement-triggered traps; kept fast by auto-pass + sorcery-speed defaults). **End of turn:** end-of-turn triggers, APNAP, same as beginning. **Refresh (not bank) resolves D8 open #4.** Remaining tuning: starting hand size, hand cap, mulligan. Deck **legality = format** concern (1v1), not core. → `rules-structure.md` §3, PLAN §2.

### D20 — Summoning: onto a bonded terrain in your realm; mana cost on card
A creature is summoned onto a **bonded terrain cell within the player's realm/mana network** (so the **realm is the deployment zone as well as the economy** — the summoning frontier creeps with the realm). Cost = the card's **mana** (a plain mana-economy play, unrelated to the Champion's own AP, D9), payable multiple times/turn as mana allows. Constraints: a **free slot on the creature's layer** (D4/D12). **Open (rec pessimistic, D14):** **summoning sickness** — a summoned creature **cannot act the turn it enters** by default; "acts immediately" is a positive (haste-like) keyword. → `rules-structure.md` §4.

### D19 — Cross-layer combat: initiation is layer-restricted, retaliation is universal
Default attack **initiation** legality (attacker → target): **Ground→**Ground ✓, Flyer ✗, Sub only-if-located. **Flyer→**Ground ✓, Flyer ✓, Sub only-if-located. **Sub→**Ground ✓ *(tentative, balance)*, Flyer ✗, Sub ✓ (if located). Subterrain is **hidden by default** (D12) → cannot be targeted unless located. All defaults; cards give exceptions (reach/anti-air/true-sight). **Retaliation is UNIVERSAL (corrects an earlier "gated by matrix" reading):** a defender **always** deals its damage back to the attacker regardless of layer — a ground creature retaliates against a diving flyer even though it can't *initiate* on flyers. Combat is mutual across layers; air superiority = an **initiative / target-selection** advantage, not damage-immunity. **Sole exception: Ranged** — a keyword making the attack **one-way** (no retaliation): "deals damage equal to its power to target creature." (Ranged combat otherwise untackled; covered by keyword later.) **Acting reveals a concealed sub:** attacking **surfaces** it → it stays **located while it remains on that hex**, and **re-conceals only when it moves away** *(interpreted from user's note — confirm next session)*. "Strike and stay hidden" is a rare positive keyword. This *is* D18 (a concealed thing risks revealing via the hard fact of acting). → `rules-structure.md` §4.

### D18 — Belief-consistency model for asymmetric information (the hard core of pillar 6)
**Principle:** *a soft claim is cheap and holds until a hard fact tests it, then the truth is applied and the lie collapses.* The engine **never fabricates a consistent lie** (rejected: regress/unbalanceable/unauthorable); **cards author claims**, the engine projects them. **No deduction engine** — the engine guarantees hard facts are truthful and enforces a **small, finite set of conservation laws** (e.g. *claimed mana costs this turn ≤ public network max*, card-count conservation) that auto-collapse mechanically-impossible claims; **all other deduction is the human's** (UI surfaces hard facts). **Collapse → full truth** by default (incl. which of a masked pool it was).
**Resource border (a principle, not a list):** *standing state public; the private-resource ledger hidden; any cost with a board footprint self-revealing* ⇒ **a spell is mimickable iff its whole cost is payable from the hidden mana ledger.** Defaults: mana **network public** (needed for denial, D8), mana **spend/live-balance hidden** (engine of cost-deception + "mana for a trick?" bluffs), **hand size public** (count; contents private), **AP public** (max & current — surprises come from instant-speed *timing*, D5, not hidden state), footprint costs (sacrifice/unbond/discard) **self-revealing**. Only standing quantity hidden = **live mana balance** (minimal carve-out from D7). Interacts with D8 #4 (bank vs refresh).
**Representation:** the atomic primitive is a **`face`** — a per-observer overlay (claimed identity + stat modifiers) a **permanent** carries; this **unifies** creature-mimicry (enter *with* a face) and spell-mimicry (an effect *applies* a face), with the card's trace showing the same face. Composable combinators — **`ChooseOne[…]`** (modal, private caster choice → true state) and **`Mimic(face)`** (applies a face over an object's whole Aether life — stack + trace, hiding true identity). Key capability: **events/effects carry a per-observer projected form, not just objects** — and since `face` is itself an effect, projecting it **mutates the opponent's view state, board objects included** (a buffed creature carries a *true* modifier + a per-observer *claimed* modifier: **modifiers can be per-observer**). Trace and board stay consistent (one authored `face`); the divergence rides along until a hard fact collapses it. Honest and bluff casts of the same Mimic card are **indistinguishable** to the opponent. **Open:** default spell-resolution visibility (lean Model 2: true by default, Mimic overrides). → `design-asymmetric-information.md`, `rules-structure.md` §9.

### D17 — Card-type taxonomy: "Spell" as umbrella; type is a queryable tag
**Card type is a data-driven queryable tag (pillar 5), not a fixed class** — the engine has a type system with default behaviors per tag; cards can bend type; the type *list* is content that grows. **"Spell" = the umbrella** for anything **cast through the Aether** (matches MtG's real usage). Structural backbone = *what resolution leaves behind*:
- **Play-permanents:** **Creature** (mobile; Attack/Life/AP, D10), **Structure** (stationary, **non-carryable**, location-based; **subtypes** e.g. *Building* + others — absorbs non-equippable "artifacts"), **Item** (**carryable** — pick up / equip). Dead permanents → **graves/ruins in Play** (D16).
- **Trace-only:** **Rite** (the one-shot type; resolves to an Aether trace, no permanent).
**Outside the Spell umbrella** (pre-game / separate economy, never cast through the Aether): **Map, Champion, Terrain**. **Type-as-tag with subtypes** is adopted (not a fixed enum). ("Artifact" dissolves: equippable → Item, stationary → Structure.)
**Opens:** (1) **Item** equip/carry details (equips to creature/Champion? drops on a hex to be picked up?); (2) **Structure** — ground-slot vs hex-level (rec hex-level); attackable/Life (rec yes → ruins); blocks movement/LOS?; build on Terrain? → PLAN §3.2; card-taxonomy step in `knowledge-capture-plan.md`.

### D16 — Unified zone model: Hand / Library / Play / Aether; no graveyard; multi-zone allowed
Zones: **Hand, Library** (deck), **Play** (permanents on the Board), and **Aether** — a per-observer **timeline**. The Aether unifies the **stack** and the spell-**graveyard**: a spell is one object that slides `Hand → front of the `now` marker (pending, LIFO = the stack) → across `now` → a **trace** in the past`. So stack and graveyard are the **same zone at different positions relative to `now`**, not two zones (one object moving, never copied). Abilities also leave traces. **No graveyard zone:** dead **creatures become graves in Play**, keeping a board location (spatial reanimation, pillar 2); spells live as Aether traces. Aether knowledge is **per-observer** (pillar 6) — your view of history is itself hideable. The engine also **allows a card in multiple zones at once** (digital-only) — kept as a *capability*, not a default/mechanic until a concrete use earns it.
**Resolved:** (1) **Traces fade** on a **configurable** window — this is what makes the model a net *simplification* (recent past interactable, old past drops away) and a color-specialization axis. (2) **Graves take no slot** — hex-level markers (view-toggleable UI). (3) **Timeline distance is mechanical** — a spell can push a trace **into the future** to **re-cast** it; such time-manipulation cards are **deferred** (start simple) but the axis is real, keep it open. (4) **Multi-zone, concretely:** casting a Play-permanent leaves **both** a permanent in Play **and** an **anchored summon/build trace** in the Aether. Two removal identities: **kill** (target the permanent → death → grave, fires death-triggers) vs **un-summon** (delete the anchored trace → the permanent vanishes as a **rewind**: no death, no grave, no triggers) — and **un-summon only works while the trace hasn't faded**, so fade **locks a permanent in** after a window. Emergent depth from multi-zone + fade. (5) **Terminology confirmed:** zones are **Hand / Library / Play / Aether**; **Board** stays the spatial grid; **Discard/Graveyard deleted**; card text says *traces*/*graves*, never "graveyard." → glossary, `rules-structure.md` §2, `design-interaction-stack.md`.

### D15 — Defend rule: two candidate variants, to be resolved by playtest
Collapses the redundant `defended`-flag + AP into **one quantity** (reopens the "defending is free" part of D10 and the defend-once corollary D14b). Two coherent packages to playtest:
- **V1 — Exhaust (`1!AP`):** defending costs `1!AP` (`!` = "exhaust to 0"). A creature defends at most once/turn and only while it has AP, so acting (move/attack) can spend the AP it would otherwise defend with. **Keeps AP in ℕ** (the negative-AP `1?AP` variant is rejected — ugly domain). Merits: clean "exhaust" model; a card granting **+1 AP** turns an apparently-tapped creature into a **surprise blocker** (combo + pillar-6 deception). Watch-point: **moving also exhausts** → maneuver can disable blocking (pillar-2 tension — good or feel-bad? playtest).
- **V2 — Delete defend-once:** defending is **free and unlimited**; the limiter is **persistent damage (D14)** — Life becomes the defensive-stamina budget (chumps block once by dying; tanks block several). Wall counterplay = out-damage it or **bypass via layers/flank** (pillars 2, D12). **No per-turn defend state at all.** Watch-point: tanky defense could stall (tuning).
Resolve **empirically** via a minimal combat sandbox (first slice of M1) with the defend rule as a config toggle. → reopens D10/D14b; `rules-structure.md` §4, `design-economy.md`.

**Cross-reference (2026-08-06):** the Champion-retaliation question in `design-champions.md` (Open questions, "Champion retaliation") proposes two candidate rules riding this same defend-cost lever — Option A (`1AP` to defend, reprising V1 above) and Option B (a `!`-costed action forbids defending that turn). Whichever this D15 playtest settles on should be checked against that unification goal.

### D14 — Design principle: pessimistic (additive) defaults
**A rule's default is the weakest *still-functional-and-fun* case; cards improve on it via *positive* lines.** Keywords read as granted abilities, not restrictions — negative lines ("may only defend once," "cannot X") are dispreferred as defaults (they feel worse), though allowed occasionally for flavor/balance. **Guardrail:** "worst case" = weakest-but-complete, never literally crippled — the base game must stand on its own as a satisfying game. Companion to "simplest rule that still exposes a hook." **Corollaries decided now:** (a) **Damage persists** across turns; **no automatic end-of-turn healing** — healing is a special ability/effect (fixes the MtG behavior the user dislikes); Life is persistent state, 0 Life → destroyed. (b) **Defend-once is the pessimistic default**; *multi-defend* is a **positive keyword** (Bulwark/Guardian-type), while `cannot defend` remains an occasional negative keyword (D10). → `rules-structure.md` header + §4; memory `pessimistic-defaults`.

### D13 — Combat damage: mutual, simultaneous, attacker-assigns, gang-up
Accepted package. Scope: sequential → **one attacker vs a hex's declared defenders** now; many-to-many rides the deferred phased scheduler (D3). **Invariant:** a Combat resolves into **directed damage events** (`attacker → target(s)`, `target → attacker`), each independently preventable/modifiable/redirectable (pillar 5) — so Ranged/First Strike/Trample/retaliation-immunity are modifiers, never new rules. **Defaults:** (1) **mutual** — attacker and defenders damage each other (Ranged = "takes no retaliation" keyword); (2) **simultaneous** — both sides' damage computed from the pre-combat state, so "both die" is possible (First Strike = opt-in sequencing keyword); (3) **attacker assigns** its Attack across the declared defenders (engine exposes a damage-assignment decision point); (4) **gang-up** — every declared defender deals its Attack to the attacker. **Undefended** (zero defenders): attacker assigns its Attack among targets of its choice on the hex (creatures, or the Champion → win path), no retaliation. Deferred as keywords/tuning: Ranged/First Strike/Trample/numbers, and **cross-layer targeting** (D12) = the next combat sub-question. → `rules-structure.md` §4, PLAN §3.4.

### D12 — A hex has three vertical layers (ground / air / sub), each capacity 3
Completing D4's "reserved corners." A hex holds **three occupancy layers** — **ground**, **above (flying)**, **below (submerged/subterranean)** — each with capacity **3** (the tactical-vs-crowding compromise: enough to guard key creatures, not a scrum). The engine represents a cell as three distinct occupancy spaces; adjacency/LOS/combat are potentially per-layer (details deferred). **The below layer is hidden by default** (pillar 6): submerged occupancy appears only in its owner's view; the opponent sees nothing there unless Detection/reveal applies. **Reveal / view-merge is an open perception question** (how a "reveal" spell merges the hidden sub-view into the opponent's view — scope, duration, granularity). Fits the existing per-observer perception layer cleanly (reveal = a visibility-modifier), so it is *structurally* supported already; the mechanic details are content. → `rules-structure.md` §1, `design-asymmetric-information.md`.

### D11 — The map is a fourth match component: a card, sized to the terrain deck
A legal match loadout is **four** things: card deck, **terrain deck**, Champion, **and a map** (all legality-constrained). **Maps are a strategic choice and come in sizes; map size determines terrain-deck size** (map legality is tied to size). A **map card** specifies: (1) **form** — which hex cells exist and their connections; "holes" are **void/aether** terrain (present as data with special functionality, not absent cells); (2) both players' **starting positions**; (3) each player's **home zone** around their start, sized to **exactly the terrain-deck size**, filled **randomly** with that player's terrain deck at game start (this *is* the D8 "home base"); (4) a **neutral area** with a predefined terrain-generation procedure (usually fixed basics, possibly randomized); (5) optional **landmarks** with special rules (e.g., first creature to enter → its Champion draws). The engine consumes **one resolved map** as data (consistent with cell-as-data). **Open (pre-game, deferrable):** in 1v1 both players bring a map — the selection/ban mechanism to pick the one played. → `rules-structure.md` §1, `design-resources-terrain.md`; resolves D8's home-base + terrain↔hex + terrain-deck-size questions.

### D10 — Creatures run on Action Points; mana is one shared pool
**Mana is a single shared pool per player** (channeled by the Champion, D8/D9) drawn on by the Champion's spells/abilities **and every creature's mana-abilities** — this is what makes the Champion a "channeler." **Creatures have a second, private economy: Action Points (AP).** A creature spends its own AP to **move, fight, and activate abilities**; abilities may cost a mix of `mana + AP` (Champion abilities cost the same shape, `mana + AP` — see D9). **A creature is three numbers: Attack / Life / Action Points.** AP **subsumes** the old Movement stat (moving costs AP, rec 1/hex) and the "move-once/attack-once" rules (both are AP purchases → multi-attack/hit-and-run are emergent); **Range demotes to a keyword.** The repeating pattern across the game: *every actor = shared mana + a private AP budget.* **Champion↔AP (confirmed, D9 revised 2026-08-06):** the Champion has its own AP budget and spends it directly, exactly like a creature — one combat/action model for all entities, no gating resource. **Move/attack are default *abilities*, not rules:** every creature has replaceable `1AP: Move` and `3!AP: Attack`. **The `!` cost:** `xAP` spends exactly x; **`x!AP`** requires x then consumes all remaining AP — so `3!` attack = no multi-attack emergently (a non-`!` attack would allow it). **Defending is free**; `cannot defend` is a common keyword, not a default (avoids disincentivizing attacks / board clog). Remaining tuning levers: AP refresh/carryover, Champion base AP. → `design-economy.md`; rewrites `rules-structure.md` §4.

### D9 — Champion runs on mana + Action Points, like a creature; killing it wins
**Revised 2026-08-06** — supersedes the original one-per-turn "Channel" model (kept below for history). The Champion is **not a bespoke third resource model**; it runs the **same two-resource shape as a creature** (D10): **mana** (spent on spells/units, many per turn, shared pool) and its own **Action Points** (private, refills each turn), spent on **draw a card, bond a terrain, move, fight, and activate abilities**. Mechanically the Champion is a special king-like creature — exactly one per side, its death ends the game — not a second combat model (pillar 5). Baseline example costs (tuning, not locked; full ability list still undesigned): `5*AP` draw (replaces the automatic per-turn draw), `2*AP` bond (the D8 once/turn bond limit, now expressed via the new `*` once-per-turn cost flavor — see `design-economy.md`), `2AP`/`1AP` move (network-active/collapsed), `5!AP`/`3!AP` attack (network-active/collapsed — drain-all like a Creature's default attack), `2–5AP` abilities. **Tension** is an open resource-allocation puzzle (`move+fight`, `draw+bond`, `bond+move×2`, …) rather than a hardcoded ternary choice; the classic ramp-vs-spend tension still falls out of the numbers (`Draw+Bond` = the 7 AP baseline). **Movement stays realm-bound** — bending the leylines to follow costs effort, so the pricier move is the one that *keeps the network active* while relocating; the cheap, Creature-cost move lets it reversibly collapse instead, pausing the disconnected mana until reconnected (same mechanic as enemy blocking) — yielding the "walking channeler." **Win condition unchanged:** killing the enemy Champion wins (Duelyst-style); no separate Base; the Champion is attackable, protected only by units and by staying deep in its realm. **Open:** the Champion's actual signature-ability list, exact AP costs, and how Champion defense/retaliation works (ties to D15) are undesigned — this decision fixes the *shape* of the economy, not its content. → `design-champions.md`; resolves win-condition + Base-merge keystones and rules-structure §7/§10 opens.

**Superseded model (kept for history):** originally the Champion had **two independent economies** — mana, and a single **Channel** action per turn spent on exactly one of {bond a terrain, act as a creature (move/attack), activate a Champion ability}, with bond-vs-activate as the central tension. Replaced above because a Champion-only "Channel" resource duplicated the AP model creatures already use (pillar 5) — the Champion is now simply a special creature, not a third combat model.

### D8 — Resource system: terrain deck connected outward from the Champion
Separate terrain deck (size varies by format), laid out randomly in the home base at start. Up to once/turn, connect one terrain reachable from the Champion via already-connected, unblocked terrains — a spatial, deterministic ramp that eliminates draw-based mana/color screw. 8 colors (8 unrestricted basics + restricted non-basics). The **Champion is the network root** (answers "is the Champion the resource engine?" → yes). Denial is positional ("put the connection on hold"), reversible, and counterable. **Severing rule RESOLVED to (a) pause:** a Champion draws mana from a bonded terrain only while a path of enemy-free terrain connects it back to the Champion; an enemy on any path node **pauses** downstream mana reversibly (kill/reroute to restore). Bonding itself is permanent — only the *draw* is conditional. → `design-resources-terrain.md`. Supersedes the placeholder "Model C." **Complexity note:** this is a deliberately rich (non-simple) core system; keep the rest simple to compensate.

### D7 — Default visibility is full
Board is fully visible by default; all concealment (Mist/Submerged/Mimic) is opt-in via cards. Simplest default that still exposes the perception hook. → `design-asymmetric-information.md`, `rules-structure.md` §9.

### D6 — Traps are supported, as a special case of the stack
A trap = a pre-committed, **hidden triggered ability** (pillar 6 hides the pre-commitment) that goes on the stack when it fires. No separate subsystem. → `design-interaction-stack.md`.

### D5 — Interaction model: priority + lightweight stack (players can act on the opponent's turn)
The engine has a real priority/stack capability (LIFO, responses-to-responses). Kept tame by: (1) priority only at **defined windows** (something goes on the stack; a Combat is declared); (2) **most default cards are sorcery-speed**, so the stack is invisible to new players. Unifies instants, combat tricks, and traps into one mechanism. **Biggest complexity commitment so far**; accepted because the user wants MTG-style interaction and it feeds the deception pillar. → `design-interaction-stack.md`.

### D4 — Board is a container: a hex holds up to 3 ground creatures
A hex is larger than a creature. Up to **3 ground creatures** occupy it (alternating corners; the other 3 corners reserved for a later use — TBD). Attacks target a **hex**; the defender **declares defenders** from creatures on that hex. Enables guarding important creatures. → `rules-structure.md` §1, §4.

### D3 — Combat runs sequentially now, but stays revertible to a phased model
Default: sequential resolution (declare/resolve one attack at a time), with **defend-once-per-turn** as a tactical primitive. Minor goal: model every fight as an explicit `Combat` object (`{attackers, target hex, declared defenders} → resolve`) so sequential vs. phased is only a **scheduling policy** — a later revert is a scheduler swap, not a rewrite. Simultaneous multi-attacker-on-one-hex is the feature the phased scheduler would unlock. → `rules-structure.md` §3–4.

### D2 — Champion progression uses level bands (formats by power ceiling)
Power is a **step function**: horizontal (sidegrades) *within* a band, a discrete jump *between* bands. Matches/tournaments are defined per band ("bring a level 1–5 champion"), so players never face a champion outside their band — vertical growth never creates an unfair match. Enables phased launch (ship band 1 first) and three distinct metagames. **Open:** down-leveling (may a higher champion play a lower bracket at a capped config?). → `design-champions.md`.

### D1 — Meta/core firewall confirmed
Champion/card progression is **never** match-internal. Leveling happens outside matches, at the player's pace, as a deliberate build decision. The match core consumes a resolved loadout only. → `design-champions.md`, PLAN §6.

# Glossary

*Shared vocabulary. Keep terms consistent everywhere — code, docs, cards. Seeded by Claude; correct freely.*

**Status:** Draft (seed) · **Date:** 2026-07-23

| Term | Meaning |
|---|---|
| **Match** | One complete game between players, ending when a win condition is met. |
| **Turn** | One player's full sequence of phases. Players alternate turns. |
| **Phase** | An ordered segment of a turn (e.g. Start, Draw, Action, End). The phase list is **data**, so cards can add/skip phases. |
| **Board** | The hex grid where the match is played, produced from a **Map** card (D11). A set of hex **cells** keyed by cube/axial coordinate. |
| **Hex / Cell** | A single tile. Has queryable properties (move-cost, terrain, per-level occupants) and **three vertical levels** (D12, renamed D41). |
| **Map** | A **card** (a fourth match component alongside card deck, terrain deck, Champion) defining the board: Layout, start positions, home ground, neutral ground, each hex's Terrain Type, landmarks. Comes in **sizes**; map size = terrain-deck size (D11). See `map.md`. |
| **Layout** | *(D11, D52 — renamed from "form" to avoid colliding with Terrain Type.)* Which hex cells exist on a map and how they connect. |
| **Level** | *(Renamed from "Layer," D41.)* One of a hex's three vertical occupancy spaces — **Surface / Air (flying) / Underground (submerged)** — each capacity 3 (D12). The Underground level is hidden by default, and a Unit needs **Subterranean** to exist there at all (D42) — access and concealment are one bundled package. |
| **Subterranean** | *(D42.)* The keyword a Unit needs to exist Underground at all — gates both access and (bundled with it) the existing hidden-by-default treatment Underground already had (D12). Default gate, not an absolute wall: a specific card effect can still force a non-Subterranean unit Underground as an explicit exception. See **Ascend**/**Descend**. |
| **Ascend / Descend** | *(D42.)* A Subterranean unit's basic abilities for crossing levels — `3AP: Ascend` (Underground → Surface), `3AP: Descend` (Surface → Underground) — the only way in or out barring an explicit card exception. |
| **Area** | *(D43.)* A hex-set defined by an effect, one of three primitives: **distance** (within N of a hex), **line** (along a line through specified hexes), or **listing** (an explicit hex list). Closed set for now. Unless stated otherwise, describes hexes, not their occupants. |
| **Void / Aether** | The terrain filling a map's "holes" — present as data with special functionality, not a missing cell (D11). |
| **Home ground** | *(D11, D53, D59.)* The map-defined area around a player's start, sized to the terrain deck. Populated by a map-level rule (D53); by default, randomly filled with the player's own terrain deck at game start. |
| **Neutral ground** | *(D11, D53, D59.)* Map area outside the two home grounds — the space players bond outward into. Populated by a map-level rule (D53); by default, a fixed terrain assignment per hex. |
| **Terrain Type** | *(D52.)* A per-hex worldbuilding classification authored by the map — e.g. Forest, Open, Wetland, Shore, Elevated, Settlement, Urban, Edge (initial set, open to extending/shortening). Purely flavor: no mechanical effect. Every hex has one, independent of whichever **Element** lands there; combined, they give a hex its full name (e.g. Forest + Fire → "Fire-adapted forest"). See `map.md`. |
| **Element** | *(D51.)* The named identity of a mana color: **Light, Fire, Metal, Earth, Darkness, Ice, Water, Air.** A terrain card carries exactly one Element and no **Terrain Type** of its own — Type always comes from the map hex it lands on. See `map.md`. |
| **Landmark** | A map hex with special rules (e.g., first creature to enter → its Champion draws) (D11). |
| **Domain** | *(D37, D59.)* A grouping of zones into three families — **Mind → Aether → Matter**, i.e. **Idea → Action → Reality**. Never queried by a card or effect, but rules text uses it for the object-kind invariant: a **card** lives only in a **Mind** zone (Hand/Library/Discard), a **trace** only in an **Aether** zone (Past/Pending/Future), a **permanent** only in the **Matter** zone (Island — the only one). Also carries each domain's past→present→future narrative. |
| **Zone** | *(D16, D37, D59.)* The container an object actually sits in — one of **Hand, Library, Discard** (Mind), **Past, Pending, Future** (Aether), **Island** (Matter). **Every object is in exactly one zone at a time** (D16) — an object in one zone may *create* new, linked objects in other zones, but is never itself present in two. Identity doesn't survive a zone crossing: casting consumes the Hand object and creates a new, linked Aether trace, never "the same card" relocating. New zones may be added later. |
| **Library** | A player's draw deck; the **Mind** domain's "future" zone. |
| **Discard** | *(D37.)* The **Mind** domain's "past" zone — not a graveyard. A card discharges into Discard the **instant it's cast**, fully decoupled from whatever happens later to the permanent it produced. |
| **Island** | *(D37.)* The **Matter** domain's single zone: permanents on the Board — **Actors** and **Objects** alike. Matter has no past/present/future split — the Island is the whole domain. A permanent "on the Island" occupies the Board. |
| **Aether** | *(D38.)* A per-observer **timeline** domain of three zones: **Past** (resolved traces), **Pending** (the "immediate future" — next to resolve; today's stack, unchanged in mechanism), and **Future** (traces already instantiated but scheduled later than "next" — enables delayed effects/a re-cast pushed further out than the very next slot). **`Now` is not a zone** — see **Now marker**. "The Aether" also reads as shorthand for "whichever Aether zone." Unifies stack + spell-graveyard + history. Traces **fade** from Past after a configurable window (default 5 rounds, `Duration X` override, D50). |
| **Trace** | An Aether record left by a resolved spell/ability. Casting a permanent-producing card creates an **anchored summon/build trace** and, on resolution, a **separate, linked** permanent (D16) — two distinct objects, not one object in two zones. Traces fade; interacting with a trace (e.g. **un-summon**) works only before it fades. |
| **Physical Trace** | *(D45.)* The trace left by a Move, Attack, Ascend, or Descend action. Still enters Pending (respondable — a real priority window exists) but on resolution is **removed from the Aether entirely, zero Past residency**, bypassing Trace Duration. Gates **Quick** speed (see **Speed**). |
| **Now marker** | The present — a moving point dividing **Past** from **Pending**, **not a zone itself**. Advances past whatever's next in Pending when **both players pass priority in succession** (neither has anything left to do); an Instant trace instead advances `Now` past itself immediately and atomically as part of being played (D45) — the sole case where advancement doesn't wait for both players to pass. Distance along the timeline is otherwise mechanical (e.g. push a trace forward to re-cast). |
| **Grave** | A dead **creature's** marker left **on the Island, on its hex** — no slot consumed, view-toggleable, free/unlimited (D16). Distinct from **Ruin** (D40), which is a dead **Structure's** marker and *does* occupy a slot. |
| **Ruin** | *(D40.)* A destroyed Structure's marker, left in whichever Structure/Ruin slot (Surface or Underground) it occupied. Unlike a Grave, a Ruin **occupies its slot** — building a new Structure directly onto it replaces the ruin in one action; an explicit effect can also clear a ruin directly, independent of building. |
| **Un-summon** | Removing a permanent by deleting its anchored Aether trace — a **rewind** (no death, no grave, no death-triggers), distinct from **kill**; only works while the trace hasn't faded. |
| **Home tile** | The Champion's starting board location (usually a landmark terrain). Not a separate objective — there is **no Base** (D9). |
| **Creature** | A card summoned onto the Board, defined by **three numbers: Attack / Life / Activation Points** (D10, D58), plus abilities/keywords. |
| **Actor** | *(D44.)* {Champion, Companion, Creature} — the three types that hold their own AP and act under their own power. |
| **Object** | *(D44.)* {Structure, Item, Grave, Ruin, Terrain} — everything on the Island that isn't an Actor; needs mana funding/direction from something else. Every Object but Item also holds its own **Activation Points** (D58), the same resource an Actor holds. |
| **Permanent** | Actor or Object — i.e. anything on the Island. Unaffected by the terminology changes above; matches `ownership.md`'s existing usage. |
| **Life (persistent)** | A creature's health. **Damage persists between turns — no automatic healing** (D14); healing is a special ability; 0 Life → destroyed. |
| **Retaliation** | Damage a declared defender deals **back** to the attacker; combat is **mutual by default** (D13). Ranged creatures take no retaliation (keyword). |
| **Defend** | Declaring a creature (or Champion) as a defender of an attacked hex (D4). Costs `0*AP` (D15, resolved 2026-08-09) — free, but at most once per turn per actor, regardless of remaining AP. |
| **Pessimistic default** | Design principle (D14): a rule's default is the weakest still-functional-and-fun case; cards improve it via **positive** lines, not default restrictions. |
| **Spell** | *(D39.)* The one-shot card type: resolves to an Aether **trace**, leaves no permanent. Not an umbrella term — every card type (Creature, Companion, Spell, Structure, Item) already goes through the identical generic play-a-card procedure, so no umbrella concept is needed. |
| **Parent** | The ownership-tree link (D26/D27): the entity that produced, bonded, or currently carries a permanent. **Not every permanent has one** (unbonded terrain, a loose Item) — a creature never parents another creature or structure (D27), unless a card explicitly reassigns it ("Gain control of...", D55). A **Companion is a root only when Neutral** (D55) — a controlled Companion always has a live Champion parent. See `ownership.md`. |
| **Payment (walk)** | To fund a cost, climb a permanent's parent chain and stop at the **first** node that holds the needed resource — one general rule for every resource (D58). Activation Points/Life stop immediately (self, held by every permanent that carries them); mana can stop at a Companion (D28). A shorter walk than finding the **controller** — not the same operation. |
| **Controller** | Climb a permanent's parent chain **all the way to the top**. The root is either a Champion, or an explicitly **Neutral** node (D54) — a Companion a card has made Neutral (D55), or a permanent with no parent at all. Resolves to exactly one of **Player A / Player B / Neutral** — never "no answer" (D29 is resolved: see **Neutral**, `neutral-permanents.md`). |
| **Neutral** | *(D54.)* The third controller value, alongside Player A/Player B — the result when a permanent's controller-walk reaches a Neutral root instead of a Champion. For Terrain/Structure/Item, Neutral just means inert (nobody may activate it). For a permanent capable of acting (holds its own Activation Points and has a legal action), Neutral means it follows a **Behavior** instead. See `neutral-permanents.md`. |
| **Behavior** | *(D56.)* A named keyword (e.g. `Aggressive toward X`) that expands to a complete, deterministic decision algorithm run by a Neutral permanent during its assigned **Neutral Phase**, standing in for a player's own decisions. Internally a triggered ability; never exposed as such on card text. Reuses the standard legal-target query for targeting/reconsideration; no generalized perception or belief-state system — only per-keyword-scoped stored memory for whatever it must remember. See `neutral-permanents.md`. |
| **Neutral Phase** | *(D54, D56.)* One of two phases per round, one attributed to each player, during which permanents assigned to it refresh their Activation Points and run their **Behavior**. Both always occur every round, unconditionally, regardless of content, so their mere occurrence never leaks whether a hidden Neutral permanent exists. See `neutral-permanents.md`. |
| **Structure** | Stationary, **non-carryable** permanent (D17); subtypes e.g. *Building*. Absorbs non-equippable "artifacts." Location is (terrain, level) like a Creature, but in its own dedicated slot — **two slots per hex** (Surface = Ground+Air combined, Underground separate; D40) — separate from creature level capacity. Has Life, attackable (D24); destroyed → a **Ruin**, which occupies its slot. Cast, so summoning-sick like a Creature (D57). Its parent is the terrain it occupies: its ability's **mana** portion is funded by whoever currently controls that cell (Champion or Companion) — D24, D27, D54 — while its **Activation Points** portion is self-funded from its own pool (D58). Its **controller** is that bonder's own Champion when the terrain is controlled, or **Neutral** when it isn't (D54) — eligible for a **Behavior** if Neutral and its ability is self-payable (`neutral-permanents.md`). See `structures-items.md`. |
| **Item** | **Carryable** permanent (D17): picked up via a generic `2AP: Equip` ability every eligible actor holds, dropped via its free `0AP: Un-equip` inverse (D30); unequipped, it has no usable ability at all. Location while loose is (terrain, level), capacity-exempt (D32, D34); while equipped, its location is its carrying actor, not spatial. Has no Life — never a combat participant, removed only via an explicit effect (D34). Its parent (and payer) is whoever equipped it; becomes ownerless again if its carrier dies or un-equips it (D25, D27, D30). See `structures-items.md`. |
| **Summon** | Playing a creature onto a **bonded terrain in your realm** for its mana cost (D20). Summoning-sick by default (D14). |
| **Mana** | The **single shared pool per player**, filled by channeling bonded terrain (D8). Spent on spells, summons, and any actor's mana-abilities. Global. |
| **Activation Points (AP)** | *(D10, D58.)* A **private per-turn budget held by every permanent except Item**, each with its own explicitly printed value — self-funds the AP portion of that permanent's own ability costs directly, never climbing (`ownership.md`). Actors spend it by default on `1AP: Move` and `3!AP: Attack`; the Champion/Companion's Attack matches this same generic default, doubled to `6!AP` while network-bonded (D49). Refills each eligible turn/phase, no carryover. Whether a permanent enters with full Activation Points or at 0 (summoning-sick) depends on whether it was cast, not on its type (D57). |
| **`!` cost (`x!AP`)** | A cost flavor: **require x AP, then consume all remaining AP** (vs. plain `xAP` which spends exactly x and leaves the rest). Makes "no multi-attack" emergent — default attack is `3!AP` (D10). |
| **`*` cost (`x*AP`)** | *(Adopted 2026-08-06 for the Champion; generalized to Defend 2026-08-09, D15.)* A cost flavor: **spend exactly x AP; the action may be used at most once per turn**, regardless of leftover or later-refilled AP — unlike `!`, it does **not** drain the rest of the pool. Used for the Champion's `5*AP: Draw` / `2*AP: Bond` actions so both stay usable in the same turn while each staying capped once/turn, and for **every actor's** `0*AP: Defend` (D15) — free, but once per turn, and (at `x=0`) completely decoupled from remaining AP. See `economy.md`, `champions.md`. |
| **Default ability** | An ability every creature has unless replaced. The set: `1AP: Move`, `3!AP: Attack`, `0*AP: Defend` (D15), `2AP: Equip` / `0AP: Un-equip` for any eligible Actor (D26, D30), and — for a Subterranean creature — `3AP: Ascend` / `3AP: Descend` (D42). Base rules expressed as replaceable abilities (pillar 5), not hardcoded logic. **Zone of Control is deliberately not on this list** (D30) — a positive keyword only, per the pessimistic-default principle. |
| **Effect** | A discrete, structured change to game state. **Base rules and card text are both expressed as effects** (pillar 5). |
| **Modifier** | A continuous effect that changes the answer to a query (e.g. "+1 Movement"). |
| **Keyword** | A named, reusable ability/property from the keyword library (e.g. Flying, **Ranged N** — range is a keyword, not a core stat, D10). |
| **Query** | A question the engine asks to get a current value (cost, movement, legality). Never read a raw stat — always query. |
| **Event** | An applied state change that flows through the pipeline where cards can intercept it. |
| **True State** | The single authoritative, deterministic game state held by the engine/server. |
| **View** | What one player perceives — built by the perception layer from True State plus that player's own card-authored claims (D18); **not merely a redacted subset of True State**. Two players' views can independently diverge from truth *and* from each other (e.g. two secret stat changes on the same creature can leave each player believing a different, both-wrong value). |
| **Perception** | The query axis answering, per observer: is this visible? what does it look like? what is known? Modified by cards (Mimic, Mist, Submerged). |
| **Mimic / Submerged / Mist** | Example asymmetric-info mechanics: a unit that looks like something else / a unit hidden until detected / a region only one player can see into. See `asymmetric-information.md`. |
| **Claim** | A card-authored, possibly-false projection into an observer's view (soft channel). Holds until a **hard fact** contradicts it; then it **collapses** (D18). |
| **Hard fact / Hard channel** | Information the engine always projects truthfully (mana network, hand size, AP, positions, deaths, combat outcomes) — what falsifies claims. Opposite: **soft channel** (identity/appearance/hidden-zone contents), which cards may fake. |
| **Collapse** | When a claim is falsified by a hard fact, the observer learns the **full truth** (default), incl. which of a masked pool it was (D18). |
| **Conservation law** | One of a small, finite set of engine-enforced checks (e.g. claimed mana ≤ public max) that auto-collapse mechanically-impossible claims. The engine does **no** other deduction — humans do (D18). |
| **Live mana ledger** | The hidden running record of mana actually spent — the one standing quantity hidden by default (network is public), enabling cost-deception (D18). |
| **Face** | The atomic deception primitive (D18): a **per-observer overlay** (claimed identity + stat modifiers) a **permanent** carries over its true state. A creature can *enter with* a face; a spell can *apply* one. Governed by the belief model (collapses on a hard fact). |
| **Mimic (effect) / ChooseOne** | Effect combinators (D18): `Mimic(face)` **applies a `face`** to a permanent (and shows it on the trace); `ChooseOne[…]` is a modal effect the caster picks privately (→ true state). |
| **Champion** | *(Provisional term; "Channeler" leans in.)* A player's single on-board avatar — the only entity that draws mana from the land **and shares it**. It is the resource-network **root** (D8), the **win condition** (kill it to win, D9), and an attackable piece. Runs mana + its own **AP** like a creature (D9, revised 2026-08-06) — draw a card, bond a terrain, move, fight, collapse its network, activate abilities. Evolves between matches along paths. See `champions.md`. |
| **Collapse Network** | *(D9, under test, added 2026-08-08.)* A Champion's `0AP` ability: drops every one of its bonds outright (not a reversible pause — they're gone, re-bond from scratch). The escape valve for the **Realm** lock below — the only way to move onto unbonded ground while a network exists. |
| **Companion** | *(D22.)* A new card type between Creature and Champion: same three stats (Attack/Life/AP) as a Creature, but can **bond terrain like a channeler** — its draw stays in a **private mana pool** spendable only on its own printed abilities, never shared. Deckbuilding-gated to specific Champion(s) (a deckbuilding-time restriction only, not re-checked if control later changes, D55). Cast like a Creature (D20); acts as a **second network root** alongside the Champion (D8), and a card can make it **Neutral** (D55), at which point it's a root of the ownership graph too. See `companions.md`. |
| **Realm** | The contiguous set of terrains the Champion has bonded. *(Under test, tightened 2026-08-08, D9):* while connected, the Champion is **confined** to its realm — it may reposition onto any hex it has bonded (`2AP`) but may not step onto unbonded ground; leaving requires **Collapse Network** (`0AP`, drops every bond outright), after which it moves freely (`1AP`) like any creature. |
| **Loadout** | A Champion's fully-resolved configuration for one match (level, chosen path, unlocked abilities), produced by the meta-layer and consumed by the match core. |
| **Path** | A branch of a Champion's between-match progression tree; committing to a path gives a Champion a distinct identity. |
| **Meta-layer** | Systems *outside* the deterministic match core that persist across matches (Champion progression, unlocks, collection). |
| **Band** | A level range (e.g. 1–5) that defines a match/tournament format. Champions only face others in the same band. Power is horizontal within a band, stepping up between bands. |
| **Surface slot** | *(Renamed from "Ground slot," D41.)* One of the 3 creature positions on a hex's **Surface** level. Each of the three levels (Surface/Air/Underground, D12) holds up to 3 creatures. |
| **Combat** | An explicit fight object: `{attacking units, target hex, declared defenders}` that resolves. Scheduled sequentially by default; potentially phased later. |
| **Pending** | *(D38.)* The **Aether** domain's "immediate future" zone — traces about to resolve, next to `Now`, resolving top-down. See `interaction-stack.md`. |
| **Priority** | The right to act at a given moment; governed per-card/ability by **Speed** (D45). |
| **Speed** | *(D45.)* Every card/ability has one of four speeds, gated by Pending's live contents: **Slow** (controller's main phase only, Pending empty), **Quick** (only **Physical Traces** in Pending), **Reactive** (no **Instant Trace** in Pending), **Instant** (any time; resolves **fully atomically** — zero response window, not even from another Instant). See `interaction-stack.md`. |
| **Trap** | A pre-committed, hidden triggered ability (pillar 6) that enters Pending when its condition fires. |
| **Terrain deck** | A separate deck (distinct from the main deck) of terrain/land cards, laid out in each player's home ground at game start. Size varies by format. |
| **Terrain** | A land card occupying board space that produces mana when connected. Basic (8 colors, unrestricted) or non-basic (restricted, more powerful). |
| **Connection / Bond** | The AP-costed act (`x*AP`, at most once/turn) of adding one terrain to a network **rooted at the Champion or a Companion** (D22), via already-bonded terrain reachable from that root. |
| **Bonded (to Leyline)** | A terrain added to a player's network by whichever root performed the bond. Its **controller** is the same three-valued result as any permanent's (D54): the bonder's Champion, if a live enemy-free path currently connects it back; otherwise **Neutral**. What's still tracked separately is its **bond record** (parent): intact-but-blocked (D8's pause — an enemy sits on the path; behaves as uncontrolled for every purpose, including a Structure built on it, D24; reverts automatically the instant the path clears) vs. genuinely absent (**unbonded** — via the bonding Companion dying, D22; the Champion's own voluntary choice; an additional cost printed on a card; or a hostile targeted effect — needs a fresh Bond to restore either way). Feeds the shared pool if Champion-bonded, or that Companion's private pool if Companion-bonded (D22). |
| **Color** | One of 8 mana types, named **Element** (D51). Basic lands each produce one. |
| **On hold** | A bonded terrain whose mana is **reversibly paused** because an enemy creature occupies a node on its only path back to **its owning root** (Champion or Companion, D8/D22). Positional, non-permanent mana denial; resumes when the path clears. *(Distinct from a Companion's death, D22, which un-bonds its terrain outright rather than pausing it.)* |

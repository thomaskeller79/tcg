# Glossary

*Shared vocabulary. Keep terms consistent everywhere — code, docs, cards. Seeded by Claude; correct freely.*

**Status:** Draft (seed) · **Date:** 2026-07-23

| Term | Meaning |
|---|---|
| **Match** | One complete game between players, ending when a win condition is met. |
| **Setup** | *(D76, D114.)* The procedure that turns a Map, terrain decks, decks and Champions into the starting board state. It is Champion A's first Beginning phase: observable, with mulligan decisions, but it opens no priority. Not a domain transition (Champion/Terrain never occupy a Mind-domain zone to begin with). See `setup.md`. |
| **Turn** | One Champion's full sequence of phases. Turns alternate between Champions. |
| **Phase** | An ordered segment of a turn (e.g. Start, Draw, Action, End). The phase list is **data**, so cards can add/skip phases. |
| **Board** | The hex grid where the match is played, produced from a **Map** card (D11). A set of hex **cells** keyed by cube/axial coordinate. |
| **Hex / Cell** | A single tile. Holds **exactly one Terrain, always** (D100) — the hex is only that terrain's position in the Layout, so card text targets the **terrain**, never the hex. Has **three vertical Slices** (D12, D78); move-cost and per-Slice capacity are properties of its terrain, and occupants are derived from their own locations (D101). |
| **Map** | A **card** (a fourth match component alongside card deck, terrain deck, Champion) defining the board: Layout, start positions, home ground, neutral ground, each hex's Terrain Type, landmarks. Comes in **sizes**; map size = terrain-deck size (D11). See `map.md`. |
| **Layout** | *(D11, D52 — renamed from "form" to avoid colliding with Terrain Type.)* Which hex cells exist on a map and how they connect. |
| **Slice** | *(D12, D78.)* One of a hex's three vertical occupancy spaces, bottom to top — **Root / Ground / Sky (flying)** — each capacity 3. The Root Slice is hidden by default, and a Unit needs **Subterranean** to exist there at all (D42) — access and concealment are one bundled package. |
| **Subterranean** | *(D42.)* The keyword a Unit needs to exist in the Root Slice at all — gates both access and (bundled with it) the existing hidden-by-default treatment the Root Slice already had (D12). Default gate, not an absolute wall: a specific card effect can still force a non-Subterranean unit into the Root Slice as an explicit exception. See **Ascend**/**Descend**. |
| **Ascend / Descend** | *(D42.)* A Subterranean unit's basic abilities for crossing Slices — `3AP: Ascend` (Root → Ground), `3AP: Descend` (Ground → Root) — the only way in or out barring an explicit card exception. |
| **Area** | *(D43.)* A hex-set defined by an effect, one of three primitives: **distance** (within N of a hex), **line** (along a line through specified hexes), or **listing** (an explicit hex list). Closed set for now. Unless stated otherwise, describes hexes, not their occupants. |
| **Void / Aether** | The terrain filling a map's "holes" — present as data with special functionality, not a missing cell (D11). |
| **Home ground** | *(D11, D53, D59.)* The map-defined area around a Champion's start, sized to the terrain deck. Populated by a map-level rule (D53); by default, randomly filled with the Champion's own terrain deck at game start. |
| **Neutral ground** | *(D11, D53, D59, D76.)* Map area outside the two home grounds — the space Champions bond outward into. Has no default population rule — every map must specify which population algorithm it uses, chosen from a growing library (D76). |
| **Terrain Type** | *(D52.)* A per-hex worldbuilding classification authored by the map — e.g. Forest, Open, Wetland, Shore, Elevated, Settlement, Urban, Edge (initial set, open to extending/shortening). Purely flavor: no mechanical effect, and nothing can query it (D100). Every hex has one, independent of whichever **Element** lands there; copied onto the terrain at Setup, it gives the terrain its full name (e.g. Forest + Fire → "Fire-adapted forest"). See `map.md`. |
| **Element** | *(D51.)* The named identity of a mana color: **Light, Fire, Metal, Earth, Darkness, Ice, Water, Air.** An object's Elements are **derived**, like MTG's colour identity: the set (0–8) of Elements in the mana it produces and in its rules text (D100). A terrain card has no **Terrain Type** of its own — Type always comes from the map hex it lands on. See `map.md`. |
| **Landmark** | A map hex with special rules (e.g., first creature to enter → its Champion draws) (D11). |
| **Domain** | *(D37, D59.)* A grouping of zones into three families — **Mind → Aether → Matter**, i.e. **Idea → Action → Reality**. Never queried by a card or effect, but rules text uses it for the object-kind invariant: a **card** lives only in a **Mind** zone (Hand/Library/Discard), a **trace** only in an **Aether** zone (Past/Pending/Future), a **permanent** only in the **Matter** zone (Island — the only one). Also carries each domain's past→present→future narrative. |
| **Zone** | *(D16, D37, D59.)* The container an object actually sits in — one of **Hand, Library, Discard** (Mind), **Past, Pending, Future** (Aether), **Island** (Matter). **Every object is in exactly one zone at a time** (D16) — an object in one zone may *create* new, linked objects in other zones, but is never itself present in two. Identity doesn't survive a zone crossing: casting consumes the Hand object and creates a new, linked Aether trace, never "the same card" relocating. New zones may be added later. |
| **Library** | A Champion's draw deck; the **Mind** domain's "future" zone. Hidden from the opponent (count only); the owner sees their own remaining contents but never the true draw order (D71). |
| **Discard** | *(D37.)* The **Mind** domain's "past" zone — not a graveyard. A card discharges into Discard the **instant it's cast**, fully decoupled from whatever happens later to the permanent it produced. Hidden from the opponent by default (count only, contents private) — same shape as Hand (D71). |
| **Island** | *(D37.)* The **Matter** domain's single zone: permanents on the Board — **Actors** and **Objects** alike. Matter has no past/present/future split — the Island is the whole domain. A permanent "on the Island" occupies the Board. |
| **Aether** | *(D38.)* A per-observer **timeline** domain of three zones: **Past** (resolved traces), **Pending** (the "immediate future" — next to resolve; today's stack, unchanged in mechanism), and **Future** (traces already instantiated but scheduled later than "next" — enables delayed effects/a re-cast pushed further out than the very next slot). **`Now` is not a zone** — see **Now marker**. "The Aether" also reads as shorthand for "whichever Aether zone." Unifies stack + spell-graveyard + history. Traces **fade** from Past after a configurable window (default 5 rounds, `Duration X` override, D50). |
| **Trace** | An Aether record left by a resolved spell/ability. Casting a permanent-producing card creates an **anchored summon/build trace** and, on resolution, a **separate, linked** permanent (D16) — two distinct objects, not one object in two zones. Traces fade; interacting with a trace (e.g. **un-summon**) works only before it fades. Has a parent in the Ancestry, leaf-resolved to a Champion or Companion at creation, same shape as Creature (D81) — see `ancestry.md`. |
| **Physical Trace** | *(D45.)* The trace left by a Move, Attack, Ascend, Descend, or Defend action (D117). Still enters Pending (respondable — a real priority window exists) but on resolution is **removed from the Aether entirely, zero Past residency**, bypassing Trace Duration. Gates **Quick** speed (see **Speed**). |
| **Now marker** | The present — a moving point dividing **Past** from **Pending**, **not a zone itself**. Advances past whatever's next in Pending when **both Champions pass priority in succession** (neither has anything left to do); while an Instant trace is in Pending, `Now` instead advances automatically until the Instant has resolved (D92) — the sole case where advancement doesn't wait for both Champions to pass. Distance along the timeline is otherwise mechanical (e.g. push a trace forward to re-cast). |
| **Remnant** | *(D110, D111; working name, `PLAN.md` Track A item 39.)* The object a fallen **Creature or Companion** leaves on its terrain — the only permanents that leave anything — a **new object**, not the creature in another status. Keeps only the fallen permanent's name (its card reference, which **raise** reads); no stats, abilities or Activation Points. Slice as a loose Item (Root stays Root, otherwise Ground), so a Root Remnant is hidden; capacity-exempt. Parent is its terrain (D81), so it belongs to whoever bonded that terrain. A resource cards can require or consume. See `object-properties.md` §5. |
| **Fell / falls** | *(D110, D111.)* A permanent **falls** when it reaches 0 Life or is felled: it ceases to exist; a Creature or Companion leaves a **Remnant**, a Structure leaves nothing (a card may create a ruined Structure with a fall trigger, D111), a falling Champion ends the match. These are **immediate consequences** (D112); fall triggers ("when a creature falls") fire as ordinary triggers. Also used for costs: "fell a creature you control" (there is no "sacrifice"). |
| **Immediate consequence** | *(D112.)* What the rules themselves make happen because of an instruction, in the same step right after it — not a trigger, not a trace, no Pending entry; part of the instruction's output. Replaces MTG's state-based actions. Example: a falling permanent ceases to exist and, by type, leaves a Remnant (Creature, Companion), nothing (Structure), or ends the match (Champion). See `interaction-stack.md` §Resolution. |
| **Destroy** | *(D110.)* An object is destroyed: it ceases to exist and leaves nothing — no Remnant, no fall triggers. Works on every object (permanent, Remnant, trace, card). |
| **Raise** | *(D110, D111.)* A Remnant ceases to exist, and a permanent of its card is created at its location, by the ordinary creation rules — the opposite of fell. |
| **Un-summon** | Removing a permanent by deleting its anchored Aether trace — a **rewind**: the permanent ceases to exist without falling (no Remnant, no fall triggers); only works while the trace hasn't faded. |
| **Bounce** | *(D69.)* Matter → Mind: removes a Permanent and **creates** a new Card, read from the Permanent's current state (Markovian object creation) — never a token (there are none, D88: a bounced created object, e.g. a Fire Warrior, becomes a real, castable Card), never a relocation of the original discarded card. Champion and Terrain can never be bounced. See `object-properties.md`. |
| **Flicker** | *(D69.)* Matter → Aether: removes a Permanent and **creates** a new Trace, read from the Permanent's current state — its target/location is a forced read of wherever the Permanent currently sits, not a player choice, unless a card overrides it. See `object-properties.md`. |
| **Ceasing to exist** | *(D97.)* What happens to an object that leaves every zone (a trace fading from Past, a card removed from Discard): it is gone for good — there is no exile zone. Links through it are joined up: whatever had it as `source` takes over its `source`. A permanent ceases to exist by falling, being destroyed, Flicker, Bounce or un-summon (D110). |
| **`source`** | *(D97.)* Every object's link to its immediate predecessor (permanent → trace → card, or → the activating permanent). Only followed by card text, never used to compute properties. Not the Ancestry parent. See `object-properties.md` §2. |
| **History track** | *(D98.)* The sequence of instruction outputs (state diffs, D96) of the last **one round** — the only way card text reads the recent past ("attacked this turn"). Facts, not objects: nothing in it can be selected or targeted, and anything older can't be accessed at all. |
| **Remand** | *(D69.)* Aether → Mind: a Trace, without ever resolving into a Permanent, **creates** a new Card instead. For a permanent-producing card this follows the same rule as Bounce/Flicker; for a Spell it's open. See `object-properties.md`. |
| **Markovian object creation** | *(D69.)* The rule governing every domain transition: a created object's properties are a pure function of its immediate predecessor's *current* state only — never a deeper lineage reference, in either direction. See `object-properties.md`. |
| **Home tile** | The Champion's starting board location (usually a landmark terrain). Not a separate objective — there is **no Base** (D9). |
| **Creature** | A card summoned onto the Board, defined by **three numbers: Attack / Life / Activation Points** (D10, D58), plus abilities/keywords. |
| **Actor** | *(D44, D103, D106.)* {Champion, Companion, Creature, Structure} — the types that hold their own AP and act under their own power. Shared properties: activated abilities, Activation Points, Life, Behavior (`object-properties.md` §5). Only Actors and Traces can carry a Behavior (D106). |
| **Object** | *(D44, D103.)* {Item, Remnant, Terrain} — everything on the Island that isn't an Actor; holds no Activation Points and needs funding/direction from something else. A label only, not a property group (D103). |
| **Permanent** | Actor or Object — i.e. anything on the Island. Unaffected by the terminology changes above; matches `ancestry.md`'s existing usage. |
| **Life (persistent)** | A creature's health. **Damage persists between turns — no automatic healing** (D14); healing is a special ability; 0 Life → it **falls** (D110). |
| **Retaliation** | Damage a declared defender deals **back** to the attacker; combat is **mutual by default** (D13). Ranged creatures take no retaliation (keyword). |
| **Defend** | *(D116, D117.)* A Quick activated ability, "Defend target attack", played in response to an Attack; when its trace resolves, its creature is added to the Attack as a defender. Defenders accumulate one at a time, interleaved with tricks ("defending bit by bit", `interaction-stack.md`). Costs `1~AP`, doubled while network-bonded for a Champion or Companion — once per opponent turn while the creature has AP; the **Defender** keyword (`1AP: Defend`) allows any number. For a Neutral creature, which mode's scoring selects Defend (if any) is decided by the same Behavior mechanism as any other choice — no bespoke rule. |
| **Pessimistic default** | Design principle (D14): a rule's default is the weakest still-functional-and-fun case; cards improve it via **positive** lines, not default restrictions. |
| **Spell** | *(D39.)* The one-shot card type: resolves to an Aether **trace**, leaves no permanent. Not an umbrella term — every card type (Creature, Companion, Spell, Structure, Item) already goes through the identical generic play-a-card procedure, so no umbrella concept is needed. |
| **Ancestry** | *(D81.)* The one parent-link structure spanning every domain — Matter (permanents), Aether (Traces), and Mind (Cards) alike — not three separate rules. **Payment** and **Controller** are two different walks over it, and both answer present-tense questions only — never what produced an object or who controlled it before (D83). Every edge has an active condition; only the Bond edge can be inactive (blocked path), and neither walk traverses an inactive edge. See `ancestry.md`. |
| **Parent** | The Ancestry link (D26/D27, D81): the entity that produced, bonded, carries, or (for a Trace) activated the ability that created it — or (for a Card) whose zone currently contains it, live. **Not every permanent has one** (unbonded terrain, a loose Item) — a creature (or Trace, D81) never parents another creature/Trace/structure, unless a card explicitly reassigns it ("Gain control of...", D55). A **Companion is a root only when Neutral** (D55) — a controlled Companion always has a live Champion parent. See `ancestry.md`. |
| **Position** | *(D105.)* A permanent's terrain: follow `location` until it reaches a terrain (an equipped Item → its carrier → the carrier's terrain). Derived, never stored. Used by Flicker, Un-equip and a carrier ceasing to exist. See `object-properties.md` §5. |
| **Payment (walk)** | *(D74.)* Climb an entity's Ancestry and stop at the **first** node that holds a needed resource — one general rule for every resource (D58), serving both a **cost** ("pay 2 mana") and an **effect**'s implicit resource-holder ("add 1 mana to **your** pool," "**you** draw a card") alike. Activation Points/Life stop immediately (self, held by every permanent that carries them); mana can stop at a Companion, Hand/Library access only ever reaches a Champion (D28). Finding nothing makes a cost illegal to pay (ability unusable); finding nothing for an effect just fizzles that instruction (D33-style), which can only happen for a Neutral permanent with no live root. A shorter walk than finding the **controller** — not the same operation. No settled noun yet for the node it lands on (`ancestry.md` Open Questions). |
| **Controller** | Climb an entity's Ancestry **all the way to the top** — applies uniformly to a permanent, a Trace, or a Card (D81). If the root is a Champion, that Champion controls it; otherwise it is **Neutral** (D54) — the root is a Companion a card has made Neutral (D55), or a permanent/Trace with no parent at all. Resolves to exactly one of **Champion A / Champion B / Neutral** — never "no answer" (D29 is resolved: see **Neutral**, `neutral-permanents.md`). A Card's controller is trivially the one Champion its parent already is. |
| **Neutral** | *(D54.)* The third controller value, alongside Champion A/Champion B — the result when a permanent's controller-walk reaches a Neutral root instead of a Champion. A Neutral object's **decider** is its **Behavior** if it carries one (a property of the object, never derived from the Ancestry); otherwise it is **Dormant** (D83). See `neutral-permanents.md`. |
| **Dormant** | *(D83.)* A Neutral object without a Behavior: nobody decides for it, so its activated abilities can't be used and triggered abilities needing a choice don't happen; mandatory, choiceless triggers and static abilities still apply. Terrain/Structure/Remnant/Item losing control through the Ancestry never receive a Behavior, so they are dormant until control is restored — unless it is a Structure already carrying one (D84); only permanents holding Activation Points can carry a Behavior (D100). See `neutral-permanents.md`. |
| **Behavior** | *(D56, D62–D65.)* A named keyword (e.g. `Aggressive toward X`) that expands to a fixed, deterministic decision **policy** run by a Neutral permanent during its assigned neutral turn, standing in for a player's own decisions. Carried per object as a property, together with its neutral turn, and attached only by a card, a scenario, or a rule (D83). Never removed by gaining a controller — unused while controlled, and replaced (together with its neutral turn) only by a new assignment when the permanent becomes Neutral (D84). Only choice-bearing abilities need coverage — static and mandatory-choiceless-triggered abilities happen automatically. Structured as ordered **modes** (trigger → target → a bounded set of eligible action shapes → a strict priority list of scoring criteria), live-derived fresh every decision point rather than stored. Scores whole-turn action sequences bounded by remaining Activation Points (receding-horizon: only the next single action is ever actually taken), never a general weighted value function. Reuses the standard legal-target/legal-ability queries; no generalized perception or belief-state system — only per-keyword-scoped stored memory for whatever it must remember. See `neutral-permanents.md`. |
| **Neutral A / Neutral B** | *(D60.)* The two neutral turns' seats in the turn order — `Champion A → Neutral A → Champion B → Neutral B`. Genuine turn-order participants (priority, APNAP/simultaneous-trigger order), never "Champions" for any other purpose (no life/hand/library, never a legal `target player`). Both turns always occur every round unconditionally, regardless of content, so their mere occurrence never leaks whether a hidden Neutral permanent exists. A permanent assigned to one runs its **Behavior** there. See `neutral-permanents.md`. |
| **Structure** | Stationary, **non-carryable** permanent (D17); subtypes e.g. *Building*. Absorbs non-equippable "artifacts." Location is (terrain, Slice) like a Creature, but in its own dedicated slot — **two slots per hex** (Ground = Ground+Sky combined, Root separate; D40) — separate from creature Slice capacity. Has Life, attackable (D24); when it falls it leaves nothing and its slot is free again (D111). Enters with 0 Activation Points, like every permanent entering the Island (D89). Its parent is the terrain it occupies: its ability's **mana** portion is funded by whoever currently controls that cell (Champion or Companion) — D24, D27, D54 — while its **Activation Points** portion is self-funded from its own pool (D58). Its **controller** is that bonder's own Champion when the terrain is controlled, or **Neutral** when it isn't (D54) — eligible for a **Behavior** if Neutral and its ability is self-payable (`neutral-permanents.md`). See `structures-items.md`. |
| **Item** | **Carryable** permanent (D17): picked up via a generic `2AP: Equip` ability every eligible actor holds, dropped via its free `0AP: Un-equip` inverse (D30); unequipped, it has no usable ability at all. Location while loose is (terrain, Slice), capacity-exempt (D32, D34); while equipped, its location is its carrying actor, not spatial. Has no Life — never a combat participant, removed only via an explicit effect (D34). Its parent (and payer) is whoever equipped it; becomes ownerless again if its carrier ceases to exist or un-equips it (D25, D27, D30). See `structures-items.md`. |
| **Summon** | Playing a creature onto a **bonded terrain in your realm** for its mana cost (D20). Summoning-sick by default (D14). |
| **Mana** | **One pool per Champion**, plus one pool per Companion (D22), filled by channeling bonded terrain (D8). A Champion's pool is spent on spells, summons, and any actor's mana-abilities; a Companion's pool is scoped to its own subtree (`ancestry.md`). |
| **Activation Points (AP)** | *(D10, D58, D87, D88.)* A **private per-turn budget held by Champion, Companion, Creature and Structure**, each with its own explicitly printed value — self-funds the AP portion of that permanent's own ability costs directly, never climbing (`ancestry.md`). Terrain, Item and Remnant hold none; an AP cost on a Terrain's triggered ability climbs to its bonder (D87). Actors spend it by default on `1AP: Move`, `3~AP: Attack` and `1~AP: Defend`; the Champion/Companion's Attack matches this same generic default, doubled to `6~AP` while network-bonded (D49). Refills each eligible turn/phase, no carryover. Every permanent entering the Island enters with 0 (summoning sickness); Setup-placed permanents are not entering, and a control change leaves AP untouched (D89). |
| **`!` cost (`x!AP`)** | A cost flavor: **require x AP, then consume all remaining AP** (vs. plain `xAP` which spends exactly x and leaves the rest). Used for powerful abilities: the permanent can't act or defend until its next refresh (D116). |
| **`~` cost (`x~AP`)** | *(D116.)* A cost flavor: **spend exactly x AP; the permanent can't activate abilities until the end of this turn.** Leftover AP stays for later turns (e.g. defending on an opponent's turn). Default Attack is `3~AP` (no multi-attack, no hit-and-run) and default Defend `1~AP` (once per opponent turn). |
| **`*` cost (`x*AP`)** | A cost flavor: **spend exactly x AP; the action may be used at most once per own-turn cycle**, regardless of leftover or later-refilled AP — unlike `!`, it does **not** drain the rest of the pool. Used for the Champion's `5*AP: Draw` / `2*AP: Bond` actions so both stay usable in the same turn while each staying capped, and for a Companion's Bond. See `economy.md`, `champions.md`. |
| **Default ability** | An ability every creature has unless replaced. The set: `1AP: Move`, `3~AP: Attack`, `1~AP: Defend` (D116), `2AP: Equip` / `0AP: Un-equip` for any eligible Actor (D26, D30), and — for a Subterranean creature — `3AP: Ascend` / `3AP: Descend` (D42). Base rules expressed as replaceable abilities (pillar 5), not hardcoded logic. **Zone of Control is deliberately not on this list** (D30) — a positive keyword only, per the pessimistic-default principle. |
| **Effect** | A discrete, structured change to game state. **Base rules and card text are both expressed as effects** (pillar 5). |
| **Modifier** | A continuous effect that changes the answer to a query (e.g. "+1 Movement"). |
| **Keyword** | A named, reusable ability/property from the keyword library (e.g. Flying, **Ranged N** — range is a keyword, not a core stat, D10). |
| **Query** | A question the engine asks to get a current value (cost, movement, legality). Never read a raw stat — always query. |
| **Event** | An applied state change that flows through the pipeline where cards can intercept it. |
| **True State** | The single authoritative, deterministic game state held by the engine/server. |
| **View** | What one observer — a Champion, or a Neutral permanent for its own decisions (D85) — perceives now, a live query with no memory or inference; every perception-dependent rules check uses it, never a belief state. For a Champion it is built by the perception layer from True State plus that Champion's own card-authored claims (D18); **not merely a redacted subset of True State**. The two Champions' views can independently diverge from truth *and* from each other (e.g. two secret stat changes on the same creature can leave each Champion believing a different, both-wrong value). |
| **Perception** | The query axis answering, per observer: is this visible? what does it look like? what is known? Modified by cards (Mimic, Mist, Submerged). |
| **Mimic / Submerged / Mist** | Example asymmetric-info mechanics: a unit that looks like something else / a unit hidden until detected / a region only one Champion can see into. See `asymmetric-information.md`. |
| **Claim** | A card-authored, possibly-false projection into an observer's view (soft channel). Holds until a **hard fact** contradicts it; then it **collapses** (D18). |
| **Hard fact / Hard channel** | Information the engine always projects truthfully (mana network, hand size, AP, positions, deaths, combat outcomes) — what falsifies claims. Opposite: **soft channel** (identity/appearance/hidden-zone contents), which cards may fake. |
| **Collapse** | When a claim is falsified by a hard fact, the observer learns the **full truth** (default), incl. which of a masked pool it was (D18). |
| **Conservation law** | One of a small, finite set of engine-enforced checks (e.g. claimed mana ≤ public max) that auto-collapse mechanically-impossible claims. The engine does **no** other deduction — humans do (D18). |
| **Live mana ledger** | The hidden running record of mana actually spent — the one standing quantity hidden by default (network is public), enabling cost-deception (D18). |
| **Face** | The atomic deception primitive (D18): a **per-observer overlay** (claimed identity + stat modifiers) a **permanent** carries over its true state. A creature can *enter with* a face; a spell can *apply* one. Governed by the belief model (collapses on a hard fact). |
| **Mimic (effect) / ChooseOne** | Effect combinators (D18): `Mimic(face)` **applies a `face`** to a permanent (and shows it on the trace); `ChooseOne[…]` is a modal effect the caster picks privately (→ true state). |
| **Champion** | *(Provisional term; "Channeler" leans in.)* A player's single on-board avatar — the only entity that draws mana from the land **and shares it**. It is the resource-network **root** (D8), the **win condition** (kill it to win, D9), and an attackable piece. Runs mana + its own **AP** like a creature (D9, revised 2026-08-06) — draw a card, bond a terrain, move, fight, collapse its network, activate abilities. Evolves between matches along paths. See `champions.md`. |
| **Collapse Network** | *(D9, under test, added 2026-08-08.)* A Champion's `0AP` ability: drops every one of its bonds outright (not a reversible pause — they're gone, re-bond from scratch). The escape valve for the **Realm** lock below — the only way to move onto unbonded ground while a network exists. |
| **Companion** | *(D22.)* A new card type between Creature and Champion: same three stats (Attack/Life/AP) as a Creature, but can **bond terrain like a channeler** — its draw stays in a **private mana pool** spendable only on its own printed abilities, never shared. Deckbuilding-gated to specific Champion(s) (a deckbuilding-time restriction only, not re-checked if control later changes, D55). Cast like a Creature (D20); acts as a **second network root** alongside the Champion (D8), and a card can make it **Neutral** (D55), at which point it's a root of the Ancestry too. See `companions.md`. |
| **Realm** | The contiguous set of terrains the Champion has bonded. *(Under test, tightened 2026-08-08, D9):* while connected, the Champion is **confined** to its realm — it may reposition onto any hex it has bonded (`2AP`) but may not step onto unbonded ground; leaving requires **Collapse Network** (`0AP`, drops every bond outright), after which it moves freely (`1AP`) like any creature. |
| **Loadout** | A Champion's fully-resolved configuration for one match (level, chosen path, unlocked abilities), produced by the meta-layer and consumed by the match core. |
| **Path** | A branch of a Champion's between-match progression tree; committing to a path gives a Champion a distinct identity. |
| **Meta-layer** | Systems *outside* the deterministic match core that persist across matches (Champion progression, unlocks, collection). |
| **Band** | A level range (e.g. 1–5) that defines a match/tournament format. Champions only face others in the same band. Power is horizontal within a band, stepping up between bands. |
| **Ground slot** | One of the 3 creature positions on a hex's **Ground** Slice. Each of the three Slices (Root/Ground/Sky, D12) holds up to 3 creatures. |
| **Combat** | An explicit fight object: `{attacking units, target terrain + Slice + entity, declared defenders}` that resolves (D115). Scheduled sequentially by default; potentially phased later. |
| **Pending** | *(D38.)* The **Aether** domain's "immediate future" zone — traces about to resolve, next to `Now`, resolving top-down. See `interaction-stack.md`. |
| **Priority** | The right to act at a given moment; governed per-card/ability by **Speed** (D45). |
| **Speed** | *(D45.)* Every card/ability has one of four speeds, gated by Pending's live contents: **Slow** (controller's main phase only, Pending empty), **Quick** (only **Physical Traces** in Pending), **Reactive** (no **Instant Trace** in Pending), **Instant** (whenever no Instant is in Pending; blocks all active play until it has resolved — zero response window, not even from another Instant; triggers still resolve). See `interaction-stack.md`. |
| **Trap** | A pre-committed, hidden triggered ability (pillar 6) that enters Pending when its condition fires. |
| **Terrain deck** | A separate deck (distinct from the main deck) of terrain/land cards, laid out in each Champion's home ground at game start. Size varies by format. |
| **Terrain** | A land card occupying board space that produces mana when connected. Basic (8 colors, unrestricted) or non-basic (restricted, more powerful). |
| **Connection / Bond** | The AP-costed act (`x*AP`, at most once/turn) of adding one terrain to a network **rooted at the Champion or a Companion** (D22), via already-bonded terrain reachable from that root. |
| **Bonded (to Leyline)** | A terrain added to a player's network by whichever root performed the bond. Its **controller** is the same three-valued result as any permanent's (D54): the bonder's Champion, if a live enemy-free path currently connects it back; otherwise **Neutral**. What's still tracked separately is its **bond record** (parent): intact-but-blocked (D8's pause — an enemy sits on the path; behaves as uncontrolled for every purpose, including a Structure built on it, D24; reverts automatically the instant the path clears) vs. genuinely absent (**unbonded** — there are ways to unbond from a terrain, both by an opponent's attack and by one's own choice; needs a fresh Bond to restore). Feeds the Champion's pool if Champion-bonded, or that Companion's own pool if Companion-bonded (D22). |
| **Color** | One of 8 mana types, named **Element** (D51). Basic lands each produce one. |
| **On hold** | A bonded terrain whose mana is **reversibly paused** because an enemy creature occupies a node on its only path back to **its owning root** (Champion or Companion, D8/D22). Positional, non-permanent mana denial; resumes when the path clears. *(Distinct from a Companion's death, D22, which un-bonds its terrain outright rather than pausing it.)* |

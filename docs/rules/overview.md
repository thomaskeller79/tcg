# Rules Overview — Match Structure

*The skeleton everything hangs on. Two companion principles govern every default: **(1) the simplest rule that still exposes a hook** (see `history/knowledge-capture-plan.md` §Part A); **(2) pessimistic defaults (D14)** — the baseline is the weakest *still-functional-and-fun* case, and cards improve it with **positive** lines, never default restrictions (e.g. damage persists by default; healing is an ability).*

**Decisions:** D3–D6, D8–D14, D16, D18, D20, D21, D24, D26, D30, D37–D50 (`history/decisions.md`)

Legend: 🪝 = the mutation hook this default preserves so cards can bend it.

---

## 1. Domains, Zones, and Time (D37, D38 — supersedes the prior flat Zones model)
Three **domains** frame where an object exists and what happens as it moves through them — **Mind → Aether → Matter**, i.e. **Idea → Action → Reality**. This is a **narrative/organizational** frame, not a new mechanical query layer — no card asks "which domain is X in." Each domain has its own past/present/future structure:

- **Mind — the Card Zone.** Everything that is only a possibility. Three sections: **Discard** (past — cards already acted on), **Hand** (present), **Library** (future — not yet drawn). **A real Discard pile exists** (D37) and does **not** reopen D16's rejection of a graveyard: a card discharges into Discard the instant it's cast, fully decoupled from whatever happens later to the permanent it produced — a creature dying still only ever produces a Grave (Matter's own separate past), and its original card never returns. Card types: **Creature, Companion, Spell, Structure, Item** — **Spell** is the one-shot type (D39); no umbrella term is needed for "anything cast," since every type already shares the same generic play-a-card procedure below.
- **Aether — magic in motion.** Four regions (D38): **Past** (resolved traces, behind Now), **Now** (the dividing point, not a section), **Pending** (the "immediate future" — next to resolve; this is today's stack, unchanged in mechanism), and **Future** (traces already instantiated but scheduled later than "next" — genuinely new, enables delayed effects and a re-cast pushed further out than the very next slot). Traces normally **fade from Past after 5 rounds** (placeholder default, `Duration X` overrides per card — D50); an exception exists for **Physical Traces** (the trace left by Move/Attack/Ascend/Descend), which get **zero Past residency** — see §3/`interaction-stack.md`.
- **Matter — the Island.** Physical reality — the board (§2), spatial and tactile. **Actors** (Champion, Companion, Creature — the three types with their own AP, D44) and **Objects** (Structure, Item, Grave, Ruin, Terrain — everything else). **Permanent** = Actor or Object, i.e. anything on the Island. Only a past exists here structurally (Ruins & Graves); there's no "future" queue for physical things the way cards/traces have one. "Island" is the term actually used day-to-day; "Card Zone" and the Aether-as-domain-header are mostly documentation scaffolding.

**Every object is in exactly one zone at a time** (D16, refined 2026-08-11) — an object never occupies two zones itself, but casting a creature *creates* two distinct, linked objects: a permanent on the Island **and** a separate anchored summon-trace in the Aether (enabling *un-summon* — delete the trace, no death — vs *kill* — destroy the permanent directly, D16). Cards/traces/permanents reference each other without merging identity (Card → creates → Trace → creates → Permanent). A **Map** resolves once at game start into board data and is not part of any zone; it cannot be referenced by other game objects.
- 🪝 Zones are a named set; the **Aether** is a per-observer timeline whose traces **fade** on a configurable window. → cards reference/move between zones; new zones can be added later.

## 2. The board (Matter/Island specifics)
*Everything below elaborates the Matter domain (§1) — this is where its Actors and Objects actually sit and move.*
- **The board comes from a *map card* (D11).** A legal match brings **four** components: card deck, terrain deck, Champion, **and a map**. Maps are a strategic choice and come in **sizes**; **map size sets the terrain-deck size** (map legality is tied to size). The engine consumes **one resolved map** as data — a set of hex **cells** keyed by cube/axial coordinate; bounds emerge from which cells exist. *(A strawman sample map exists for testing; the model is map-as-content.)*
- **A map card specifies (D11):** (1) **form** — which cells exist + connections; "holes" are **void/aether** terrain (present as data with special functionality, not missing cells); (2) both **starting positions**; (3) each player's **home zone** around their start, sized to **exactly the terrain-deck size**, filled **randomly** with that player's terrain deck at game start (= the D8 home base); (4) a **neutral area** with a predefined terrain-generation procedure; (5) optional **landmarks** with special rules.
- **A hex has three vertical levels (D12, renamed D41):** **Surface / Air (flying) / Underground (submerged)**, each holding up to **3** creatures. The engine represents a cell as three distinct occupancy spaces. The **Underground level is hidden by default** (pillar 6) — visible only in its owner's view — and, since D42, a Unit needs the **Subterranean** keyword to exist there at all (Underground access and concealment are one bundled package, not two separate questions). *(3-per-level = the guard-your-key-creature vs. not-crowded compromise.)*
- **A hex has two independent Structure/Ruin slots (D24, revised D40):** a shared **Surface** slot (Ground+Air combined — Air isn't expected to be structure-dense enough to need its own) and a separate **Underground** slot (concealment kept as its own axis). Slots don't consume creature-level capacity. Controlled by whoever currently bonds that terrain cell (mirrors terrain control, §5), not by whoever built it. A destroyed Structure leaves a **Ruin** that *occupies* its slot (unlike a Grave, which is always free) — cleared by building directly over it or by an explicit effect. See `structures-items.md`.
- **An Area (D43) defines an effect's target hex-set**, one of three primitives: **distance** (all hexes within N of a hex), **line** (hexes along a line through specified hexes), or **listing** (an explicit hex list) — a closed set for now, extended later only as specific cards need more shapes. Unless stated otherwise, an area describes hexes, not their occupants.
- **No separate Base (D9):** each player's objective *is* their **Champion**, which starts on its map-defined **home tile**. Kill the enemy Champion to win (§7).
- 🪝 Each cell has *queryable* properties (move-cost, terrain tags, per-level capacity/occupants). Defaults: move-cost = 1, capacity = 3/level. → terrain, high-ground, void, impassable, capacity changes, landmarks are all **data**, not new rules.
- 🪝 The engine exposes **adjacency, distance, reachability/path, and line-of-sight** as spatial queries (path serves both movement and the D8 terrain network; LOS serves Ranged *and* Mist — named now so perception isn't a bolt-on).

## 3. Turn structure
- **Default (D21):** strict alternating turns (I-go, you-go), three phases:

  | Phase | What happens (default) |
  |---|---|
  | **Beginning** | mana / AP **refresh** (mana refreshes, no banking — D8 #4; AP refresh covers creatures and the Champion alike, D9) — **simultaneous, no state checks**. *(Card draw is no longer an automatic Beginning-phase step — as of the D9 revision it's the Champion's `5*AP: Draw` action, spent in the Action phase below.)* Then beginning-of-turn triggers go into the Aether **APNAP** (active player's first, then opponent's → opponent's resolve first). **No priority this phase to start** (simple); active-player *choices* like upkeep costs still work — only *opponent-reactive* upkeep needs a window, added later (phases are data). |
  | **Action** | active player plays spells, spends AP to move/attack/draw/bond/activate, in **any order**, until they choose to finish. Whether any given card/ability can be played at a given moment is now governed by its **Speed** (Slow/Quick/Reactive/Instant, D45 — supersedes D5/D23 and the old enumerated-window model; see `interaction-stack.md`), not a fixed per-phase window list. |
  | **End** | end-of-turn triggers, APNAP, same as Beginning. |

- 🪝 The phase list is **data the engine walks**, not hardcoded control flow. → "skip your draw," "extra Action phase," "add a priority window to Beginning" are all card/config effects.
- *Rationale:* one free-order Action phase = simpler to learn, more flexible than separate move/combat phases; forced sequencing can be imposed by cards.
- *Rationale (Beginning, since the D9 revision):* moving Draw into the Champion's AP economy leaves Beginning with exactly two jobs — refresh resources (invisible to the players, nothing to decide) and fire triggers — no player-facing action special-cased into the phase itself.

## 4. Units: acting, movement, combat
**A creature is three numbers: Attack / Life / Action Points (AP) (D10).** AP is the creature's **private per-turn action budget** (refills to max each turn, no carryover by default); mana is the **shared** pool (§5, D8). See `economy.md` for the full three-resource model.
- **Summoning (D20):** a creature is summoned onto a **bonded terrain cell in your realm** (the realm is the deployment zone as well as the economy), paying the card's **mana** (a plain mana play, unrelated to the Champion's own AP, repeatable as mana allows). Needs a free slot on the creature's level (§2, D12). 🪝 **Summoning sickness (pessimistic default, D14):** a summoned creature **can't act the turn it enters**; "acts immediately" is a positive (haste) keyword.
- **Move and attack are default *abilities*, not rules (D10), and are Quick-speed Physical actions (D45):** Every creature carries two replaceable defaults: **`1AP: Move`** (one hex per AP; a creature may enter a hex only with a free **Surface slot**, capacity 3, §2) and **`3!AP: Attack`** (targets a **hex**; **Melee** = adjacent, **Ranged N** keyword = within N). There is no hardcoded move/attack logic — just abilities with AP costs. Move/Attack traces are **Physical Traces**: they still enter Pending (respondable) but get **zero Past residency** on resolution (D45) rather than the normal Trace Duration. A creature needs the **Subterranean** keyword to move Underground at all (D42) — see **Ascend**/**Descend** below.
- **Ascend / Descend (D42):** a Subterranean creature's only way between Underground and Surface — `3AP: Ascend` (Underground → Surface), `3AP: Descend` (Surface → Underground). Underground remains hidden by default (pillar 6, D12) to anyone but its owner; a non-Subterranean unit can only end up Underground via an explicit card-effect exception.
  - **The `!` cost:** `xAP` spends exactly x (leftover AP stays usable); **`x!AP`** requires x then **consumes all remaining AP**. So default `3!AP: Attack` = no multi-attack (attacking drains you); a printed `3AP: Attack` would allow it. See `economy.md`.
  - **Abilities** may cost a mix of `mana + AP` (and either AP flavor).
  - 🪝 AP total, ability set, per-action AP costs, capacity, and legal-target set are all **queries/effects**. → +AP buffs, cheaper/pricier or replaced move/attack, flying, rooted, reach, "can't attack fliers," etc.
- **Declaring defenders (D4):** when a hex is attacked, the defending player **declares which of their creatures on that hex defend**. Default: **each creature may defend only once per turn** — the **pessimistic default (D14)**: "once" is the weak case, so *multi-defend* is a **positive keyword** (Bulwark/Guardian-type), not a negative "defends once" line. **Defend costs `0*AP` (D15):** free, but at most once per turn per actor, completely decoupled from remaining AP. `cannot defend` is an occasional negative keyword; a card can still deliberately consume a creature's Defend as part of a strong ability's own effect (opt-in, card-level). See `economy.md`, `history/decisions.md` D15.
- **Equip / Un-equip (D26, D30):** two more default abilities every eligible actor (Champion, Companion, Creature) carries alongside Move/Attack/Defend. **`2AP: Equip target Item sharing this location`** (tuning baseline, D26) picks up a loose Item, becoming its parent. **`0AP: Un-equip`** (D30, free and uncapped — unlike Defend, no known reason to cap it) drops a carried Item back to loose on the actor's current hex. Both removable/re-priceable per creature like any default ability (a beast can't wield a sword). See `ownership.md`, `structures-items.md`.
- **Zone of control:** whether a creature blocks/threatens enemy movement through its adjacent hexes. **Not a default** — consistent with the pessimistic-default principle (D14), this would hand every creature a generous, universal capability. If added at all, it's a **positive keyword** on specific creatures, not a base rule. See `history/pessimistic-default-audit.md`.
- **Combat as an explicit `Combat` object (D3):** every fight is `{attacking units, target hex, declared defenders} → resolution`. An Attack is a **Physical Trace** (D45) that sits in Pending, respondable by any Quick/Reactive/Instant-speed card before it resolves (see `interaction-stack.md`) — this is what enables combat tricks, with no bespoke Combat-specific window needed. **Default scheduling is sequential** — a `Combat` is created and resolved the instant an attack is declared. *Minor goal: keep scheduling swappable so a phased (declare-all-then-resolve, simultaneous multi-attacker) model is a later scheduler change, not a rewrite.*
- **Combat resolution (D13):** a Combat resolves into **directed damage events** — `attacker → target(s)` and `target → attacker`. Defaults: **mutual** (both sides damage each other), **simultaneous** (both computed from the pre-combat state → "both die" possible), the **attacker assigns** its Attack across the declared defenders, and **all defenders gang up** (each deals its Attack to the attacker). **Undefended** hex: attacker assigns among targets of its choice on the hex (creatures, or the Champion → win path), no retaliation. **No** dice, **no** facing/flanking/high-ground. A creature at **0 Life is destroyed** (→ becomes a **grave in Play**, D16, no slot consumed; a Structure instead becomes a **Ruin**, which *does* occupy its slot, D40); **damage persists between turns — no auto-heal** (D14).
  - 🪝 Each damage instance is an **event** through the pipeline → Ranged (no retaliation), First Strike (sequenced timing), Trample (excess carries), prevention/redirection are all modifiers, never new rules.
- **Cross-layer targeting (D19).** Default attack **initiation** legality (attacker → target): **Surface→** Surface ✓ / Air ✗ / Underground only-if-located. **Air→** Surface ✓ / Air ✓ / Underground only-if-located. **Underground→** Surface ✓ *(tentative, balance)* / Air ✗ / Underground ✓ (if located). Underground is **hidden by default** (D12) → untargetable unless located; cards give exceptions (reach/anti-air/true-sight). **Retaliation is universal:** a defender **always** deals its damage back regardless of level (a Surface creature retaliates against a diving flyer) — combat is mutual across levels; air superiority = initiative, not immunity. **Sole exception: Ranged** (keyword) — a **one-way** attack ("deals damage equal to power to target creature"; ranged combat covered by keyword later). **Acting reveals a concealed Underground unit:** attacking **surfaces** it; it stays **located while on that hex** and **re-conceals when it moves away** *(confirm)*; "strike and stay hidden" is a rare positive keyword.
- *Note:* position already matters via adjacency, Range, hex occupancy, and guarding — no combat modifiers needed to make placement meaningful.

## 5. Resources — terrain connection network (D8)
- **A separate terrain deck** (size varies by format) is laid out **randomly in the home base** at start. **Up to once/turn**, **bond** one terrain reachable from the **Champion** via already-bonded terrain. Bonding is **permanent**; bonding +1/turn is a smooth, deterministic ramp — no draw-based mana/color screw.
- **Mana draw is conditional:** a bonded terrain produces mana **only while a path of enemy-free terrain connects it back to the Champion**. An enemy creature on any path node **pauses** (reversibly) all mana downstream of it — kill it or reroute to restore.
- **8 colors:** 8 unrestricted basic lands + restricted non-basic "fancy" terrains. The **Champion is the network root** — moving it endangers the mana base.
- **A Companion (D22) is a second, independent root:** it bonds terrain the same way (its own `x*AP: Bond`, reachable from itself), but the mana feeds a **private pool** only that Companion spends — never the shared pool. Ownership follows whichever root performed the bond. See `companions.md`.
- **General cost resolution (D26):** every permanent other than a Champion has **at most one** *parent* (whoever bonded/equipped it, or — for a creature — whoever recursively paid to create it; creatures never parent other creatures or structures; a **Companion is never itself a root**, it always has a Champion parent). Paying a non-AP, non-Life cost climbs that chain and stops at the **first** Champion or Companion found (payment); AP and Life are always paid by the object itself, never climbed. A permanent's **controller** is a separate, stricter question — climb all the way to the Champion regardless of what's held along the way. **Removing or interrupting an inner node breaks the chain for its successors** — terrain (three bond states: active / interrupted / unbonded) cuts off a Structure built on it, payer and controller alike; whether a Companion's death also strips *controller* from the creatures it roots is still open (`ownership.md`).
- Denial is **positional** ("put the connection on hold" — reversible, counterable), never random.
- 🪝 Bond count, reachability, path-blocking, and what a terrain produces are all **effects/queries**. → extra bonds, bond-at-range, ignore-blocker cards, etc.
- *Note:* this is a deliberately **rich** core system (not a simple default) — its complexity is the price of a signature economy; keep other systems simple to compensate.

## 6. Deck & hand
- **Default:** deck size and max copies TBD (strawman: 30-card deck, max 3 copies). Draw 1/turn (§3). Opening hand size TBD (strawman: 5).
- 🪝 Draw count, hand size, deck legality are all queries/effects. → "draw 2," "max hand size 10," faction deckbuilding restrictions.
- Faction/color *structure* exists as a hook; flavor deferred.

## 7. Win condition
- **Default (D9):** **kill the enemy Champion.** There is **no separate Base** — the "home base" is just the Champion's start tile (usually a landmark terrain), not a destructible objective. The Champion is the objective, the economic root (D8), and the most-exposed piece all at once.
- 🪝 The win check is an **evaluated effect**, not a hardcoded `if`. → alternate win conditions ("control 5 hexes," "mill the enemy deck") are cards.

## 8. Invariants (deliberately NOT mutable)
The stable substrate cards rely on. Kept fixed on purpose:
- The game state is **deterministic**; randomness only via defined shuffles/draws with a seed.
- An **event pipeline** and a **query layer** always exist (cards hook them; they can't be removed).
- A single authoritative **True State** exists, and a **per-observer view layer** always exists — every player always has *some* view (asymmetric info, pillar 6). *What* a player sees is mutable; that they get a projected view is not.
- Turns alternate between players **unless an effect explicitly says otherwise** (the alternation itself is default, but the two-player-seat framework is invariant for now).
- A match **must be able to end** (win checks are always evaluated).

## 9. Visibility / perception (default)
- **Default:** the board is **fully visible** to both players. Every unit shows its true identity and stats. Concealment is **opt-in via cards** (Mist, Submerged, Mimic).
- 🪝 Visibility, appearance, and knowledge are **perception queries** per observer (see `asymmetric-information.md`). Default answers = "visible / true / known." → Mist, Submerged, Mimic, Detection are modifiers on these queries.
- *Rationale:* full visibility is the simplest default that still exposes the perception hook; hidden info is layered on by cards, exactly per the "simplest rule that still exposes a hook" principle.
- **Belief consistency (D18):** deceptions are card-authored **claims** that hold until a **hard fact** tests them, then **collapse to full truth**. The engine enforces only a small set of **conservation laws** (no deduction engine — humans reason). Border: *standing state public, private-resource ledger hidden, footprint costs self-revealing* → only the **live mana balance** is hidden by default. See `asymmetric-information.md`.

## 10. Champions (in-match default)
- **Default:** each player has exactly one **Champion** on the board, placed at start on its **home tile**, already bonded to that tile (1 mana live from turn 1, rather than needing a live Bond + a full turn cycle first). It is a special card type (HP, position) simulated by the core; **it is attackable and its death loses the game** (§7, D9). **First-player AP asymmetry (D48):** the Champion of the player who goes first enters with **reduced** starting AP (placeholder: 4) instead of its full Activation Capacity; the second player's Champion enters at full Activation Capacity — a first-move-advantage balancing lever, exact number deferred to tuning.
- **Mana + Action Points (D9):** the Champion runs the **same two-resource shape as a creature** — *mana* (spent on spells/units, many/turn) and its own **AP** (private, refills each turn), spent on **draw a card, bond a terrain, move, fight, activate abilities** — not a bespoke third model. Baseline example (tuning): 7 AP; `5*AP` draw (replaces the automatic per-turn draw), `2*AP` bond (the D8 once/turn limit), `2AP`/`1AP` move (see the realm constraint below), `6!AP`/`3!AP` attack (network-active/disconnected — now unified with the generic Actor default of `3!AP` doubled while bonded, D49, rather than a bespoke figure). No hardcoded "pick one" — see `champions.md` for the full breakdown, the tension, and open items (ability list, defend/retaliation).
- **Mana is a per-turn snapshot:** mana is refreshed once per Beginning phase (the sum of currently-connected/producing bonded terrain at that instant) — a bond made mid-turn is permanent but doesn't credit the pool until the *following* Beginning phase, the same "no retroactive unlock this turn" shape as summoning sickness (D14).
- **Realm-bound movement (D9, D8):** the Champion is the network root. While its network is currently connected, it is **confined to its own bonded territory** — it may reposition onto any hex it has itself bonded, at `2AP`, but may never step onto ground it hasn't claimed. To go anywhere else it must first pay `0AP` for the **Collapse Network** ability, which drops every bond outright (not a reversible pause — they're gone, re-bond from scratch); once disconnected it moves freely at `1AP` like any creature.
- The core consumes a **resolved Champion loadout** (level/path/abilities) as input; **no progression logic runs inside a match** (that's the meta-layer). See `champions.md`.
- 🪝 Champion AP is a per-turn resource query (default = 7, tuning); abilities/stats are the same effects/queries/modifiers as any card. → extra AP, free/reactive abilities, paths, level-ups, in-match buffs all hook the same machinery.

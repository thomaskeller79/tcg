# Rules Overview — Match Structure

*The skeleton everything hangs on. Two companion principles govern every default: **(1) the simplest rule that still exposes a hook** (see `history/knowledge-capture-plan.md` §Part A); **(2) pessimistic defaults (D14)** — the baseline is the weakest *still-functional-and-fun* case, and cards improve it with **positive** lines, never default restrictions (e.g. damage persists by default; healing is an ability).*

**Decisions:** D3–D6, D8–D14, D16, D18, D20, D21, D24, D26, D30, D37–D50, D54–D58, D66–D68, D71, D75, D76, D77, D86, D100, D101, D102, D103, D114, D115, D116, D117 (`history/decisions.md`)

Legend: 🪝 = the mutation hook this default preserves so cards can bend it.

## 1. Match Setup & Domains (D11, D37, D38, D59)
**A legal match brings four components: card deck, terrain deck, Champion, and a map** (D11) — assembled before play begins, cutting across all three domains below (a map, in particular, isn't part of any zone at all — see below). Maps are a strategic choice and come in **sizes**; **map size sets the terrain-deck size** (map legality is tied to size). **How these four components actually combine into a starting board state is `setup.md` (D76)** — a background, non-observable procedure, not a domain transition (Champion and Terrain never occupy a Mind-domain zone to begin with).

Two nested terms describe where an object is. A **zone** is the container an object actually sits in — **every object is in exactly one zone at a time** (D16); the zones are **Hand, Library, Discard, Past, Pending, Future, Island**. A **domain** groups those zones into three families — **Mind → Aether → Matter**, i.e. **Idea → Action → Reality**. Domain is a **narrative/organizational** frame, never a mechanical query — no card asks "which domain is X in" — but rules text leans on it for one structural invariant: **a card exists only in a Mind zone, a trace only in an Aether zone, a permanent only in the Matter zone** (D59). Each domain also tells its own past/present/future story:

- **Mind — cards.** Everything that is only a possibility. Three zones: **Discard** (past — cards already acted on), **Hand** (present), **Library** (future — not yet drawn). A card discharges into Discard the instant it's cast, fully decoupled from whatever happens later to the trace and possibly the permanent it produced — a creature falling only ever produces a Remnant on the Island, and its original card never returns (D37, D110). Card types: **Creature, Companion, Spell, Structure, Item** (**Spell** is the one-shot type, D39). **All three Mind zones are hidden from the opponent by default and internally ordered** — each shows the opponent a count only, never contents; the owner sees Hand/Discard in true order, and Library's remaining contents (but never its draw order, hidden even from the owner) (D71). See `asymmetric-information.md`.
- **Aether — magic in motion.** Three zones (D38): **Past** (resolved traces), **Pending** (the "immediate future" — next to resolve), and **Future** (traces already instantiated but scheduled later than "next" — enables delayed effects and a re-cast pushed further out than the very next slot). **`Now` is not a zone** — it's the moving point dividing Past from Pending. It advances past whatever's next in Pending when **both Champions pass priority in succession**; while an Instant trace is in Pending, `Now` instead advances automatically until it has resolved (D45, D92), never waiting for both Champions to pass. Traces normally **fade from Past after 5 rounds** (placeholder default, `Duration X` overrides per card — D50); an exception exists for **Physical Traces** (the trace left by Move/Attack/Ascend/Descend), which get **zero Past residency** — see §3/`interaction-stack.md`.
- **Matter — the Island.** Physical reality — the board (§2), spatial and tactile. **Actors** (Champion, Companion, Creature, Structure — the types with their own AP, D44, D103) and **Objects** (Item, Remnant, Terrain — everything else). **Permanent** = Actor or Object, i.e. anything on the Island. Matter holds a **single zone, the Island** — no past/present/future split, since dividing physical space that way would be artificial. "Island" is the term used day-to-day; "Mind" and "Aether" as domain headers are mostly documentation scaffolding, though "the Aether" is common shorthand for "whichever Aether zone a trace is in."

**One object never occupies two zones itself** (D16) — but casting a creature *creates* two distinct, linked objects: a permanent on the Island **and** a separate anchored summon-trace in the Aether (enabling *un-summon* — delete the trace; the permanent ceases to exist without falling — vs *fell* — the permanent falls and leaves a Remnant, D16, D110). Cards/traces/permanents reference each other without merging identity (Card → creates → Trace → creates → Permanent). A **Map** resolves once at game start into board data and is not part of any zone; it cannot be referenced by other game objects.
- 🪝 Zones are a named set; the **Aether** is a per-observer timeline whose traces **fade** on a configurable window. → cards reference/move between zones; new zones can be added later.

## 2. The board (Matter/Island specifics)
*Everything below elaborates the Matter domain (§1) — this is where its Actors and Objects actually sit and move.*
- **The board comes from a *map card* (D11).** The engine consumes **one resolved map** as data — a set of hex **cells** keyed by cube/axial coordinate; bounds emerge from which cells exist. *(A strawman sample map exists for testing; the model is map-as-content.)*
- **A map card specifies:** Layout (which cells exist and connect), both starting positions, each Champion's home ground, the neutral ground, each hex's Terrain Type, and optional landmarks — see `map.md` for the full breakdown.
- **A hex has three vertical Slices (D12, D41, D78), bottom to top: Root / Ground / Sky (flying)**, each holding up to **3** creatures. The engine represents a cell as three distinct occupancy spaces. The **Root Slice is hidden by default** (pillar 6) — visible only in its owner's view — and, since D42, a Unit needs the **Subterranean** keyword to get there at all (Root access and concealment are one bundled package, not two separate questions). *(3-per-Slice = the guard-your-key-creature vs. not-crowded compromise.)*
- **A Slice's 3-slot capacity is a hard cap, and a creature may enter a Slice only if every occupant shares its controller.** A Slice can become **mixed** — occupants under different controllers — only through a control change (automatic or by effect; control changes never check occupancy). Nobody can enter a mixed Slice, so it blocks both sides; its co-located enemies can fight each other (exact combat rules: `PLAN.md` Track A item 25); it becomes uniform again once one side has left or fallen (D86). Moving, summoning, or relocating into a Slice checks both entry conditions **against the acting Champion's own belief state** at declare time; if a chosen destination turns out illegal against true state (a hidden occupant the Champion's belief state didn't show — the only way this can happen, since an unconcealed Slice's occupancy is always accurately known), the instantiate step becomes iterative: the player redirects to a different candidate destination or explicitly cancels, repeating until one succeeds or they stop — cost already paid is never returned either way (D68). See `ancestry.md`, `interaction-stack.md`.
- **A hex has two independent Structure slots (D24, D40):** a shared **Ground** slot (Ground+Sky combined — Sky isn't expected to be structure-dense enough to need its own) and a separate **Root** slot (concealment kept as its own axis). Slots don't consume creature-Slice capacity. Controlled by whoever currently bonds that terrain cell (mirrors terrain control, §5), not by whoever built it. A fallen Structure leaves nothing, freeing its slot (D111). See `structures-items.md`.
- **An Area (D43) defines an effect's target hex-set**, one of three primitives: **distance** (all hexes within N of a hex), **line** (hexes along a line through specified hexes), or **listing** (an explicit hex list) — a closed set for now, extended later only as specific cards need more shapes. Unless stated otherwise, an area describes hexes, not their occupants.
- **No separate Base (D9):** each player's objective *is* their **Champion**, which starts on its map-defined **home tile**. Kill the enemy Champion to win (§7).
- **Every hex holds exactly one Terrain, always (D100)** — a hex is that terrain's position in the Layout, and card text targets the terrain, never the hex. Terrain can't be destroyed; an effect that would remove one replaces it with a void terrain.
- 🪝 Each terrain has *queryable* properties (move-cost, per-Slice capacity), changed by static abilities; occupants are derived from their own locations (D101). Defaults: move-cost = 1, capacity = 3/Slice. → terrain, high-ground, void, impassable, capacity changes, landmarks are all **data**, not new rules.
- 🪝 The engine exposes **adjacency, distance, reachability/path, and line-of-sight** as spatial queries (path serves both movement and the D8 terrain network; LOS serves Ranged *and* Mist — named now so perception isn't a bolt-on).

## 3. Turn structure
- **Default (D21):** strict alternating turns (I-go, you-go), three phases:

  | Phase | What happens (default) |
  |---|---|
  | **Beginning** | mana **refresh** (no banking — D8 #4) and AP **refresh** (covers creatures and the Champion alike, D9) — two independently-skippable effects (D76), run **simultaneous, no state checks** when both apply. *(Card draw is not an automatic Beginning-phase step — it's the Champion's `5*AP: Draw` action, spent in the Action phase below.)* Then beginning-of-turn triggers go into the Aether **APNAP** (active Champion's first, then opponent's → opponent's resolve first). **No priority this phase to start** (simple); active-Champion *choices* like upkeep costs still work — only *opponent-reactive* upkeep needs a window, added later (phases are data). |
  | **Action** | active Champion plays spells, spends AP to move/attack/draw/bond/activate, in **any order**, until they choose to finish. Whether any given card/ability can be played at a given moment is governed by its **Speed** (Slow/Quick/Reactive/Instant, D45; see `interaction-stack.md`), not a fixed per-phase window list. |
  | **End** | end-of-turn triggers, APNAP, same as Beginning. |

- 🪝 The phase list is **data the engine walks**, not hardcoded control flow. → "skip your draw," "extra Action phase," "add a priority window to Beginning" are all card/config effects.
- **Round 1 (D114):** Champion A's first Beginning phase is Setup — Setup's procedure replaces its refresh, then its trigger step runs as usual. See `setup.md`.
- *Rationale:* one free-order Action phase = simpler to learn, more flexible than separate move/combat phases; forced sequencing can be imposed by cards.
- *Rationale (Beginning):* Draw living in the Champion's AP economy rather than as an automatic step leaves Beginning with exactly two jobs — refresh resources (invisible to the players, nothing to decide) and fire triggers — no player-facing action special-cased into the phase itself.
- **Neutral turns (D54, D56, D60):** a round is four turns, not two — `Champion A → Neutral A → Champion B → Neutral B`. **Neutral A** and **Neutral B** are genuine turn-order participants (not phases nested inside a Champion's turn, not a borrowed Champion identity), each a full turn (Beginning/Action/End) for the permanents assigned to it. Both always occur every round unconditionally, regardless of whether anything is assigned to either — an information-parity requirement, not an optimization to skip. Turn order, priority, and simultaneous-trigger ordering are the standard multiplayer rule (active-first, then each other participant in turn order) applied to all four seats uniformly. Neutral A/B are never "Champions" for any other purpose (no life/hand/library, never a legal `target player`). See `neutral-permanents.md`.

## 4. Units: acting, movement, combat
**A creature is three numbers: Attack / Life / Activation Points (AP) (D10, D58).** AP is the creature's **private per-turn action budget** (refills to max each turn, no carryover by default); mana is the **Champion's** pool (§5, D8). See `economy.md` for the full three-resource model.
- **Summoning (D20):** a creature is summoned onto a **bonded terrain cell in your realm** (the realm is the deployment zone as well as the economy), paying the card's **mana** (a plain mana play, unrelated to the Champion's own AP, repeatable as mana allows). Needs a free slot on the creature's Slice (§2, D12). 🪝 **Summoning sickness (pessimistic default, D14):** a summoned creature **can't act the turn it enters**; "acts immediately" is a positive (haste) keyword. This applies to **every permanent entering the Island**, not just Creature: it enters with 0 Activation Points, however it got there (D89).
- **Move and attack are default *abilities*, not rules (D10), and are Slow-speed Physical actions (D45, D75):** Every creature carries two replaceable defaults: **`1AP: Move`** (one hex per AP; a creature may enter a hex only with a free **Ground slot**, capacity 3, §2) and **`3~AP: Attack`** (targets a **terrain, a Slice and an entity**, D100, D115; **Melee** = adjacent, **Ranged N** keyword = within N). There is no hardcoded move/attack logic — just abilities with AP costs. Move/Attack traces are **Physical Traces**: they still enter Pending (respondable) but get **zero Past residency** on resolution (D45) rather than the normal Trace Duration. A creature needs the **Subterranean** keyword to move to the Root Slice at all (D42) — see **Ascend**/**Descend** below.
- **Ascend / Descend (D42):** a Subterranean creature's only way between the Root and Ground Slices — `3AP: Ascend` (Root → Ground), `3AP: Descend` (Ground → Root). The Root Slice remains hidden by default (pillar 6, D12) to anyone but its owner, with a narrow proximity exception (D67, `asymmetric-information.md`). **Entering either Slice is blind exactly when the mover's controller has no qualifying presence (via any of their permanents) already covering the destination — this is not an "Ascend is safe, Descend isn't" rule.** Ascending is *usually* safe only because the controller is usually already standing right there; Ascending into a Mist-concealed Ground hex is exactly as blind as any Descend. Descending is *usually* blind only because the controller usually has no independent Root-Slice presence at that hex yet — but a second Subterranean scout already stationed there or adjacent removes the blindness entirely, since visibility belongs to the Champion, not to the specific mover (D67). Unlike every other destination-choosing action, Ascend/Descend have nowhere else to go if the destination turns out illegal (it's always "this hex, other Slice") — when they are blind, it's a genuine, non-redirectable gamble, resolved via D68's iterative-instantiate rule same as any other hidden-info mismatch, just with no second candidate to fall back on. A non-Subterranean unit can only end up in the Root Slice via an explicit card-effect exception, with the same blind-entry risk.
  - **AP cost flavors (D116):** `xAP` spends exactly x (leftover AP stays usable); **`x!AP`** requires x then **consumes all remaining AP**; **`x~AP`** spends x and the permanent **can't activate abilities until the end of this turn** (leftover AP stays for later turns, e.g. defending); `x*AP` is once per own-turn cycle. So default `3~AP: Attack` = no multi-attack and no hit-and-run; a printed `3AP: Attack` would allow both. See `economy.md`.
  - **Abilities** may cost a mix of `mana + AP` (and either AP flavor).
  - 🪝 AP total, ability set, per-action AP costs, capacity, and legal-target set are all **queries/effects**. → +AP buffs, cheaper/pricier or replaced move/attack, flying, rooted, reach, "can't attack fliers," etc.
- **Defending (D4, D115, D117):** the attacked entity's creatures on the attacked terrain **defend by responding to the Attack** with their Defend ability, one at a time, interleaved with tricks; at resolution the Attack checks whether it still has a defender (`interaction-stack.md` §Combat integration). Eligible: creatures in the attacked Slice; when Ground is attacked, Sky creatures too. Ground creatures never defend the Sky; Root only defends Root. **Defend is a default ability costing `1~AP` (D116):** a creature can defend once per opponent turn while it has AP — the **pessimistic default (D14)**; the **Defender** keyword (`1AP: Defend`) allows any number per turn. A creature that spent all its AP, or used a `!` ability, can't defend until its next refresh. `cannot defend` is an occasional negative keyword. See `economy.md`, `history/decisions.md` D116.
- **Equip / Un-equip (D26, D30):** two more default abilities every eligible actor (Champion, Companion, Creature) carries alongside Move/Attack/Defend. **`2AP: Equip target Item sharing this location`** (tuning baseline, D26) picks up a loose Item, becoming its parent. **`0AP: Un-equip`** (D30, free and uncapped — unlike Defend, no known reason to cap it) drops a carried Item back to loose on the actor's current hex. Both removable/re-priceable per creature like any default ability (a beast can't wield a sword). See `ancestry.md`, `structures-items.md`.
- **Zone of control:** whether a creature blocks/threatens enemy movement through its adjacent hexes. **Not a default** — consistent with the pessimistic-default principle (D14), this would hand every creature a generous, universal capability. If added at all, it's a **positive keyword** on specific creatures, not a base rule. See `history/pessimistic-default-audit.md`.
- **Combat as an explicit `Combat` object (D3):** every fight is `{attacking units, target terrain + Slice + entity, declared defenders} → resolution`. An Attack is a **Physical Trace** (D45) that sits in Pending, respondable by any Quick/Reactive/Instant-speed card before it resolves (see `interaction-stack.md`) — this is what enables combat tricks, with no bespoke Combat-specific window needed. **Default scheduling is sequential** — one attack at a time; its `Combat` resolves when the Attack trace resolves, with the defenders added to it by Defend responses (D117). *Minor goal: keep scheduling swappable so a phased (declare-all-then-resolve, simultaneous multi-attacker) model is a later scheduler change, not a rewrite.*
- **Combat resolution (D13):** a Combat resolves into **directed damage events** — `attacker → target(s)` and `target → attacker`. Defaults: **mutual** (both sides damage each other), **simultaneous** (both computed from the pre-combat state → "both fall" possible), the **attacker assigns** its Attack across the declared defenders, and **all defenders gang up** (each deals its Attack to the attacker). **Undefended** (D115): the attacker assigns among the attacked entity's permanents in the attacked Slice of that terrain (creatures, Structures, or the Champion → win path), no retaliation. **No** dice, **no** facing/flanking/high-ground. A creature at **0 Life falls** (→ ceases to exist and leaves a **Remnant** on the Island, D110, no slot consumed; a fallen Structure leaves nothing, D111); **damage persists between turns — no auto-heal** (D14).
  - 🪝 Each damage instance is an **event** through the pipeline → Ranged (no retaliation), First Strike (sequenced timing), Trample (excess carries), prevention/redirection are all modifiers, never new rules.
- **What an attack targets (D115).** An attack names a **terrain, a Slice and an entity** (Champion A, Champion B, or Neutral — one entity, the Neutral A/B seats only name turns). Slice and entity are selected automatically when only one is legal. **Slice rule (D19, D115):** an attacker may only attack its own Slice, plus **Sky → Ground** — Root→Root, Ground→Ground, Sky→Sky, Sky→Ground; every other pair is a keyword's job (e.g. Track C's Root→Ground ambush keyword, a Ground→Root digger). **Legality:** the attack can be declared only if the attacking Champion's view shows at least one permanent of the attacked entity in the attacked Slice of that terrain — so a hidden Root creature can't be attacked, or probed for, until located (D12). If the only such permanent leaves in response and nobody defends, the attack does nothing and its AP stays spent. **Retaliation is universal:** a defender **always** deals its damage back regardless of Slice (a Ground creature retaliates against a diving flyer) — combat is mutual across Slices; air superiority = initiative, not immunity. **Sole exception: Ranged** (keyword) — a **one-way** attack ("deals damage equal to power to target creature"; ranged combat covered by keyword later). Whether a Ranged attack can be defended at all is open (`PLAN.md` Track A item 45).
- *Note:* position already matters via adjacency, Range, hex occupancy, and guarding — no combat modifiers needed to make placement meaningful.

## 5. Resources — terrain connection network (D8)
- **A separate terrain deck** (size varies by format) is laid out **randomly in each Champion's home ground** at start. **Up to once/turn**, **bond** one terrain reachable from the **Champion** via already-bonded terrain. Bonding is **permanent**; bonding +1/turn is a smooth, deterministic ramp — no draw-based mana/color screw.
- **Mana draw is conditional:** a bonded terrain produces mana **only while a path of enemy-free terrain connects it back to the Champion**. An enemy creature on any path node **pauses** (reversibly) all mana downstream of it — kill it or reroute to restore.
- **8 colors:** 8 unrestricted basic lands + restricted non-basic "fancy" terrains. The **Champion is the network root** — moving it endangers the mana base.
- **A Companion (D22) is a second, independent root:** it bonds terrain the same way (its own `x*AP: Bond`, reachable from itself), but the mana feeds **its own pool**, spent only within that Companion's subtree — never the Champion's pool. Ancestry follows whichever root performed the bond. See `companions.md`.
- **General cost resolution (D26, D58):** every permanent other than a Champion has **at most one** *parent* (whoever bonded/equipped it, or — for a creature — whoever recursively paid to create it; creatures never parent other creatures or structures, unless a card reassigns one, D55; a **Companion is a root only when Neutral**, D55 — otherwise it always has a Champion parent). Paying a cost climbs that chain and stops at the **first** node holding the needed resource, one rule for every resource type (D58) — Activation Points and Life are always paid by the object itself, never climbed, since it's always the first node checked. A permanent's **controller** is a separate, stricter question — climb all the way to the root, resolving to Champion A, Champion B, or **Neutral** (D54). **Removing or interrupting an inner node breaks the chain for its successors** — terrain losing its controller (its bond blocked, or unbonded outright, D54) cuts off a Structure built on it, payer and controller alike; a Companion ceasing to exist likewise strips *controller* from the creatures it roots (`ancestry.md`), while a card making a Companion **Neutral** instead leaves its subtree structurally intact (`neutral-permanents.md`).
- Denial is **positional** ("put the connection on hold" — reversible, counterable), never random.
- 🪝 Bond count, reachability, path-blocking, and what a terrain produces are all **effects/queries**. → extra bonds, bond-at-range, ignore-blocker cards, etc.
- *Note:* this is a deliberately **rich** core system (not a simple default) — its complexity is the price of a signature economy; keep other systems simple to compensate.

## 6. Deck & hand
- **Default:** deck size and max copies TBD (strawman: 30-card deck, max 3 copies). Draw 1/turn (§3). Opening hand size TBD (strawman: 5).

## 7. Win condition
- **Default (D9):** **fell the enemy Champion**; both falling from the same instruction is a draw (D113). There is **no separate Base** — a Champion's "home ground" is just the area around its start tile (usually a landmark terrain), not a destructible objective. The Champion is the objective, the economic root (D8), and the most-exposed piece all at once.
- 🪝 The win check is an **evaluated effect**, not a hardcoded `if`. → alternate win conditions ("control 5 hexes," "mill the enemy deck") are cards.

## 8. Invariants (deliberately NOT mutable)
The stable substrate cards rely on. Kept fixed on purpose:
- The game state is **deterministic**; randomness only via defined shuffles/draws with a seed.
- An **event pipeline** and a **query layer** always exist (cards hook them; they can't be removed).
- A single authoritative **True State** exists, and a **per-observer view layer** always exists — every Champion always has *some* view (asymmetric info, pillar 6). *What* a Champion sees is mutable; that they get a projected view is not.
- Turns alternate between Champions **unless an effect explicitly says otherwise** (the alternation itself is default, but the two-Champion-seat framework is invariant for now).
- A match **must be able to end** (win checks are always evaluated).

## 9. Visibility / perception (default)
- **Default:** the board is **fully visible** to both Champions. Every unit shows its true identity and stats. Concealment is **opt-in via cards** (Mist, Submerged, Mimic).
- 🪝 Visibility, appearance, and knowledge are **perception queries** per observer (see `asymmetric-information.md`). Default answers = "visible / true / known." → Mist, Submerged, Mimic, Detection are modifiers on these queries.
- *Rationale:* full visibility is the simplest default that still exposes the perception hook; hidden info is layered on by cards, exactly per the "simplest rule that still exposes a hook" principle.
- **Belief consistency (D18):** deceptions are card-authored **claims** that hold until a **hard fact** tests them, then **collapse to full truth**. The engine enforces only a small set of **conservation laws** (no deduction engine — humans reason). Border: *standing state public, private-resource ledger hidden, footprint costs self-revealing* → only the **live mana balance** is hidden by default. See `asymmetric-information.md`.

## 10. Champions (in-match default)
- **Default:** each player has exactly one **Champion** on the board, placed by Setup (`setup.md`, D76, D114) on its **home tile**, already bonded to that tile (1 mana live from turn 1 — kept deliberately, D77, for tempo and to tax rushing the Champion out of its own realm). It is a special card type (HP, position) simulated by the core; **it is attackable, and its falling loses the game** (§7, D9). **First-turn AP asymmetry (D114):** Setup raises both Champions to at least **4 Activation Points**; the first-move-advantage lever is that Setup is the first player's opening Beginning phase, so that player gets no AP-refresh on turn 1 — exact starting number still deferred to tuning.
- **Mana + Activation Points (D9):** the Champion runs the **same two-resource shape as a creature** — *mana* (spent on spells/units, many/turn) and its own **AP** (private, refills each turn), spent on **draw a card, bond a terrain, move, fight, activate abilities** — not a bespoke third model. Baseline example (tuning): 7 AP; `5*AP` draw (replaces the automatic per-turn draw), `2*AP` bond (the D8 once/turn limit), `2AP`/`1AP` move (see the realm constraint below), `6~AP`/`3~AP` attack (network-active/disconnected — the generic Actor default of `3~AP` doubled while bonded, D49, D116). No hardcoded "pick one" — see `champions.md` for the full breakdown, the tension, and open items (ability list, defend/retaliation).
- **Mana credits live, per-permanent (D77):** the instant a bonded, reachable producer hasn't yet drawn this cycle, its production credits straight to the pool and its flag flips — no Beginning-phase delay. Both the pool and every flag reset at the owner's own Beginning phase.
- **Realm-bound movement (D9, D8):** the Champion is the network root. While its network is currently connected, it is **confined to its own bonded territory** — it may reposition onto any hex it has itself bonded, at `2AP`, but may never step onto ground it hasn't claimed. To go anywhere else it must first pay `0AP` for the **Collapse Network** ability, which drops every bond outright (not a reversible pause — they're gone, re-bond from scratch); once disconnected it moves freely at `1AP` like any creature.
- The core consumes a **resolved Champion loadout** (level/path/abilities) as input; **no progression logic runs inside a match** (that's the meta-layer). See `champions.md`.
- 🪝 Champion AP is a per-turn resource query (default = 7, tuning); abilities/stats are the same effects/queries/modifiers as any card. → extra AP, free/reactive abilities, paths, level-ups, in-match buffs all hook the same machinery.
